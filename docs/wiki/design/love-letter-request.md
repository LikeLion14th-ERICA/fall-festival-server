# 디자인팀 전달용: 한 줄 러브레터

[위키 홈](../README.md) · [제품 명세](../product/love-letter.md) · 읽는 때: 러브레터 화면 설계·전달

축제 ‘동심’에 맞춰 어린 시절 몰래 쪽지를 건네는 느낌이다. 홈 메뉴와 소개 화면은
[스탬프 시작 화면 참조](README.md)의 구조·간격을 재사용한다. 소개 화면 CTA는
`작성하고 러브레터 받기`다. 모바일 390×844와 더 좁은 화면, 긴 번역 문자열 및
스크린리더 순서를 확인해 달라.

| 화면·상태 | 표시·행동·API |
|---|---|
| 홈 진입·소개 | 홈 러브레터 버튼, 운영 안내·CTA. `GET /love-letter-guide` |
| 작성·동의 | 성별 남/여, 이름/닉네임 20자, 한 줄 100자, 연락처 100자. 성인 자기 확인·본인 연락처·제공 동의·등록 후 철회 불가. 필수값·길이·키보드 상태 |
| 등록 중·60초 대기 | 중복 입력 방지, 등록 성공 후 서버의 `drawAvailableAt`까지 남은 시간 표시. `POST /love-letters`, `GET /love-letter-status` |
| 추첨 가능·쪽지 부족·오류 | 60초 후 추첨 버튼 활성. 부족 시 등록은 유지하고 추첨만 재시도. `POST /love-letter-draws` |
| 봉투 도착·열기 | 추첨 성공 때 결과 ID만 받고, 열기를 눌러 이름·내용·연락처 표시. `POST /love-letter-results/{id}/open` |
| 재방문·다음 날 | 가장 최근 연락처만 표시, 다음 날 새 CTA 활성. `GET /love-letter-status` |
| 사전 참여 | 링크 연결 성공·사용됨·만료·참여 충돌 및 지정일 추첨·부족. `POST /love-letter-invitations/claim`, `/love-letter-seeded-draws` |
| 신고·차단·제한·종료 | 신고 확인, 차단 시 연락처 숨김, 참여 제한과 운영 종료 안내. 신고 API·내 상태 API |
| 관리자 | 사전 등록·링크 재발급, 신고 검토, 쪽지 차단, 작성자·신고자 제한/해제, 운영 중지 |

연락처는 텍스트와 복사 버튼으로 제공한다. 앱이 자동으로 전화·SNS를 열지 않는다.
처음 작성한 이름·내용·연락처는 다른 언어로 번역하지 않는다. 색상 외 상태 표현,
명확한 label·focus·오류 연결과 동의 내역의 읽기 순서를 제공해 달라. 각 화면에
LOVE-001, API, 정상·빈·오류·비활성 전환 조건을 주석으로 표시해 달라.

이 문서는 팀에 바로 전달할 요청서다. 실제 Figma 편집과 디자인팀 메시지 발송은
별도 협업 경로에서 수행한다.

## 화면별 전환·컴포넌트 확인

| 기능 ID·화면 | 표시 필드와 버튼 | 전환 조건 |
|---|---|---|
| LOVE-001 홈·소개 | 홈 메뉴, 동심 소개, `작성하고 러브레터 받기` | guide 활성 시 CTA, 운영 전·종료는 기간 안내 |
| LOVE-001 작성 | 성별 2선택, 이름 20자·내용 100자·연락처 100자 카운터, 성인·본인 연락처·제공 동의, 수정·철회 불가 안내, 등록 | 모든 필수값·동의 후 요청. 키보드가 버튼을 가리지 않는 좁은 화면 |
| LOVE-001 처리·대기 | 진행 상태와 비활성 등록 버튼, 서버 기준 60초 카운트다운 | 등록 즉시 `WAITING`. 재방문 시 `drawAvailableAt`에서 남은 시간을 다시 계산. 등록 재전송은 같은 요청 키 |
| LOVE-001 추첨·부족 | 60초 후 추첨 버튼, 처리 중 중복 입력 방지, 부족 안내·재시도 | `DRAW_READY`일 때 추첨. `LOVE_WAITING`이면 남은 시간 안내, `LOVE_POOL_EMPTY`이면 등록 유지·같은 날 재시도 |
| LOVE-001 봉투·결과 | 봉투, 열기, 이름·한 줄·연락처 텍스트와 복사, 신고 | 결과 ID만 받은 뒤 사용자가 열 때 공개. 자동 외부 앱 실행 없음 |
| LOVE-001 재방문 | 가장 최근 연락처 텍스트·복사, 다음 참여 시각 | 당일 버튼 비활성, 다음 날 새 작성 활성. 새 성공 결과로 교체 |
| LOVE-001 사전 연결 | 연결 성공·만료·이미 사용·참여 충돌, 지정일 추첨 | 연결 성공 시 새 브라우저 쿠키 사용. 쪽지 부족이면 지정일 안 재시도 |
| LOVE-001 차단·제한·종료 | 차단 안내, 제한 안내, 종료 안내 | 연락처 숨김. 당일 재추첨 없음. 종료 즉시 열람 불가 |
| ADM-LOVE 사전 등록 | 동의 확보 시각·버전, 지정일, 작성 필드, 일회용 링크 1회 표시·재발급 | 남녀 초기 쪽지와 동의 확인 뒤 활성화 |
| ADM-LOVE 신고 검토 | 신고 목록·상세, 쪽지 차단, 작성자·신고자 제한·해제 | 자동 차단 없음. 관리자 개인정보 상세 열람 감사 |

모든 상태에서 390×844와 320px 폭, 긴 영어·중국어 문자열, 글자 확대, 스크린리더의
label·focus·오류 연결, 복사 성공 안내와 색상 외 상태 표현을 확인해 달라.
