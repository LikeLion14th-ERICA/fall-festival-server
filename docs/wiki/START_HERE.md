# 처음 프로젝트를 숙지할 때

[위키 홈](README.md)

처음 참여하거나 프로젝트 맥락을 잃었을 때 아래 순서로 읽는다.
전체 위키·API·배포 문서를 한 번에 읽을 필요는 없다.

1. [루트 규칙](../../AGENTS.md)
2. [제품 개요](product/overview.md)와 [근거 자료](product/sources.md)
3. [내비게이션](product/navigation.md)과 [기능 범위](product/scope.md)
4. [작업 절차](workflow/task.md)
5. [작업별 읽기 표](README.md)에서 지금 맡은 작업의 상세 페이지

이후 작업은 루트 규칙과 작업별 읽기 표에서 시작한다. 전체 제품을 재독하지 않아도
되지만 해당 도메인의 최신 규칙과 승인 상태는 확인한다.

## 예시

- 지도 필터 수정: 지도·학교 용어·API 해당 절. UI 변경은 다국어·품질, 저장 변경은 보안도 읽는다.
- 커밋 제목 작성: 커밋 규칙. 제품·지도·배포 문서는 재독하지 않는다.
- 문서 링크 수정: 위키 관리와 대상 페이지. 제품 동작 변경이 없으면 Figma 재열람은 불필요하다.
