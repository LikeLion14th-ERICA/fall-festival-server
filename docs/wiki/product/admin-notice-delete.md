# 관리자 공지 삭제

[위키 홈](../README.md) · [관리자 기능 목차](admin.md) · 읽는 때: 공지 삭제·사용자 노출 제거 변경

ADM-NOTICE-003 · 관리자 공지 삭제

기능 기본 정보

| 항목 | 명세 내용 |
| --- | --- |
| 기능 ID | ADM-NOTICE-003 |
| 기능명 | 관리자 공지 삭제 |
| 기능 목적 | 관리자가 등록된 공지를 삭제하고, 삭제 성공 시 관리자 공지 목록 및 사용자 웹에서 해당 공지의 노출을 제거한다. |
| 진입 경로 | 관리자 웹페이지 → 공지 관리 → 기존 공지 → `삭제` |
| 사용 대상과 권한 | 관리자 페이지 접근 권한이 있는 총학생회 운영자 |
| 실행 조건 | 삭제 대상 공지가 존재하며 관리자가 해당 공지를 삭제할 권한이 있는 상태 |
| 삭제 대상 | 관리자가 선택한 기존 공지 1건 |
| 삭제 방식 | 삭제 확인창에서 최종 확인한 경우에만 삭제 요청 |
| 반영 대상 | 관리자 공지 목록 / 사용자 웹 홈 / 사용자 공지 목록 및 상세 |
| 관련 기능 | ADM-NOTICE-001 관리자 공지 목록 관리 |

## 1. 삭제 처리 흐름

| 순서 | 관리자 동작 및 시스템 처리 |
| --- | --- |
| 1 | 관리자가 공지 목록에서 삭제할 공지의 `삭제` 버튼을 선택한다. |
| 2 | 시스템이 해당 공지의 삭제 확인창을 표시한다. |
| 3 | 관리자가 삭제 대상 공지 제목을 확인한다. |
| 4 | `취소` 선택 시 확인창을 닫고 기존 상태를 유지한다. |
| 5 | `삭제` 선택 시 해당 공지에 대한 삭제 요청을 진행한다. |
| 6 | 삭제 요청 처리 중에는 동일 공지에 대한 추가 삭제 요청을 제한한다. |
| 7 | 삭제 성공 시 해당 공지를 삭제 완료 상태로 처리한다. |
| 8 | 관리자 공지 목록에서 해당 공지를 제거하고 최신 공지 목록을 다시 조회한다. |
| 9 | 사용자 웹의 홈, 공지 목록 및 공지 상세에서 해당 공지의 노출을 제거한다. |
| 10 | 관리자 화면에는 최신 공지 목록을 표시한다. |

## 2. 삭제 확인창

| 항목 | 내용 |
| --- | --- |
| 노출 조건 | 관리자 공지 목록에서 `삭제` 버튼을 선택한 경우 |
| 확인 문구 | `이 공지를 삭제하시겠습니까?` |
| 삭제 대상 | 삭제하려는 공지의 제목 표시 |
| 취소 버튼 | `취소` |
| 취소 동작 | 확인창을 닫고 공지 데이터 및 목록 상태 유지 |
| 삭제 버튼 | `삭제` |
| 삭제 동작 | 선택한 공지에 대한 삭제 요청 실행 |
| 삭제 요청 중 | 삭제 버튼의 중복 입력을 제한한다. |

## 3. 동작 규칙

| 항목 | 규칙 |
| --- | --- |
| 즉시 삭제 방지 | 공지 목록의 `삭제` 버튼 선택만으로 실제 삭제하지 않는다. |
| 삭제 조건 | 삭제 확인창에서 관리자가 `삭제`를 최종 선택한 경우에만 삭제 요청을 진행한다. |
| 취소 처리 | `취소` 선택 시 서버 데이터에 어떠한 변경도 발생하지 않는다. |
| 삭제 처리 기준 | 서버에서 삭제 요청이 성공한 경우에만 삭제 완료로 처리한다. |
| 관리자 목록 제거 | 삭제 성공이 확인된 이후 해당 공지를 목록에서 제거한다. |
| 사용자 웹 제거 | 삭제 성공한 공지는 사용자 웹에서 더 이상 노출하지 않는다. |
| 공지 상세 접근 | 삭제된 공지는 사용자 웹의 기존 상세 주소로 접근하더라도 공지 내용을 제공하지 않는다. |
| 목록 갱신 | 삭제 성공 후 서버 기준 최신 공지 목록을 다시 조회한다. |
| 중복 요청 방지 | 삭제 요청 처리 중에는 동일 공지의 삭제 요청을 추가로 실행하지 않는다. |
| 삭제 실패 | 삭제 완료로 처리하지 않고 기존 공지를 그대로 유지한다. |
| 데이터 기준 | 관리자 화면의 임시 상태가 아닌 서버의 최종 처리 결과를 기준으로 삭제 여부를 판단한다. |

## 4. 사용자 웹 반영 규칙

| 항목 | 규칙 |
| --- | --- |
| 반영 조건 | 관리자 삭제 요청이 서버에서 정상 처리된 경우 |
| 반영 대상 | 사용자 웹 홈 / 공지 목록 / 공지 상세 |
| 홈 | 해당 공지가 홈에 노출 중인 경우 삭제 성공 후 노출에서 제거한다. |
| 공지 목록 | 삭제된 공지를 목록에서 제거한다. |
| 공지 상세 | 삭제된 공지의 상세 내용을 더 이상 제공하지 않는다. |
| 반영 방식 | 사용자가 직접 새로고침하지 않아도 최신 공지 상태가 반영되도록 한다. |
| 반영 시간 | 삭제 성공 후 최대 5초 이내 사용자 화면에 반영한다. |
| 삭제 실패 | 사용자 화면의 기존 공지 노출 상태를 유지한다. |

## 5. 삭제 데이터 처리 기준

| 항목 | 규칙 |
| --- | --- |
| 서비스상 삭제 | 삭제 성공한 공지는 관리자 및 사용자 서비스에서 더 이상 정상 공지로 조회하지 않는다. |
| 목록 조회 대상 | ADM-NOTICE-001의 일반 공지 목록 조회 대상에서 삭제된 공지를 제외한다. |
| 사용자 조회 대상 | 사용자 공지 목록 및 상세 조회 대상에서도 삭제된 공지를 제외한다. |
| 첨부 이미지 | 삭제된 공지에 등록되어 있던 이미지는 사용자 화면에서 더 이상 노출하지 않는다. |
| 실제 데이터 삭제 방식 | 물리 삭제 또는 논리 삭제 등 DB 내부 구현 방식은 개발팀에서 결정한다. |

## 6. 복수 관리자 및 이미 삭제된 공지 처리

| 상황 | 처리 |
| --- | --- |
| 다른 관리자가 먼저 해당 공지를 삭제 | 현재 관리자의 삭제 요청 시 이미 존재하지 않는 공지임을 확인한다. |
| 이미 삭제된 공지 삭제 요청 | 추가 삭제를 실행하지 않고 최신 공지 목록을 다시 조회한다. |
| 안내 문구 | `이미 삭제된 공지입니다.` |
| 목록 갱신 | 이미 삭제된 공지를 목록에서 제거하고 서버의 최신 공지 목록으로 갱신한다. |
| 복수 관리자 화면 | 이후 조회 시 서버에 존재하는 최신 공지 목록을 기준으로 표시한다. |

## 7. 예외 상황 및 오류 처리

| 상황 | 대응 |
| --- | --- |
| 삭제 요청 실패 | 해당 공지를 삭제하지 않고 기존 상태를 유지한다. |
| 관리자 목록 | 삭제 실패 시 해당 공지를 기존 목록에 계속 표시한다. |
| 사용자 웹 | 삭제 실패 시 해당 공지를 기존과 동일하게 노출한다. |
| 삭제 실패 오류 메시지 | `공지를 삭제하지 못했습니다. 다시 시도해주세요.` |
| 삭제 실패 후 재시도 | 오류 확인 후 관리자가 다시 `삭제`를 선택해 삭제 요청을 진행할 수 있다. |
| 삭제 요청 중 중복 입력 | 기존 삭제 요청 완료 전까지 추가 삭제 요청을 제한한다. |
| 삭제 성공 후 목록 재조회 실패 | 삭제된 공지는 제거된 상태로 처리하되 목록 갱신 실패 안내 후 재조회할 수 있도록 한다. |
| 이미 삭제된 공지 | `이미 삭제된 공지입니다.` 안내 후 최신 목록으로 갱신한다. |
| 사용자 화면 갱신 실패 | 마지막으로 정상 수신한 상태를 유지하고 이후 갱신 성공 시 삭제된 공지를 제거한다. |

## 8. 완료 기준

| 확인 항목 | 완료 기준 |
| --- | --- |
| 삭제 진입 | 관리자 공지 목록의 `삭제` 버튼을 통해 삭제 절차를 시작할 수 있다. |
| 삭제 확인 | 삭제 확인창을 거친 경우에만 실제 삭제 요청이 발생한다. |
| 삭제 대상 확인 | 확인창에서 삭제할 공지 제목을 확인할 수 있다. |
| 취소 | `취소` 선택 시 공지 데이터에 어떠한 변경도 발생하지 않는다. |
| 삭제 대상 | 관리자가 선택한 공지 1건이 정확하게 삭제된다. |
| 중복 요청 | 삭제 요청 처리 중 동일 공지에 대한 중복 삭제 요청이 발생하지 않는다. |
| 관리자 반영 | 삭제 성공 후 해당 공지가 관리자 공지 목록에서 제거된다. |
| 목록 갱신 | 삭제 성공 후 서버 기준 최신 공지 목록으로 갱신된다. |
| 사용자 홈 반영 | 삭제된 공지가 홈에 노출 중이었다면 해당 노출이 제거된다. |
| 사용자 공지 목록 | 삭제된 공지가 사용자 공지 목록에서 제거된다. |
| 사용자 공지 상세 | 삭제된 공지의 기존 상세 주소로 공지 내용을 조회할 수 없다. |
| 사용자 자동 반영 | 삭제 성공 후 최대 5초 이내 사용자 웹에 삭제 상태가 반영된다. |
| 삭제 실패 | 삭제 실패 시 관리자 및 사용자 화면에서 기존 공지를 유지한다. |
| 오류 안내 | 삭제 실패 시 오류 메시지가 표시되고 관리자가 다시 시도할 수 있다. |
| 동시 삭제 | 다른 관리자가 먼저 삭제한 경우 중복 삭제하지 않고 최신 목록으로 갱신한다. |
