# 지도

[위키 홈](../README.md) · 읽는 때: 전체·구역 지도, 핀·필터와 다른 기능의 위치 연결 변경

## MAP-001 · 지도

로그인 없이 축제 전체 공간과 구역별 배치, 장소 위치와 이용 정보를 확인한다. 하단
내비게이션, [부스&마켓 상세](spaces.md)의 위치 버튼과 [외부인 티켓](ticket.md)의
티켓존 위치 버튼에서 진입한다.

하단 메뉴에서 처음 들어오면 전체 일러스트 지도, `전체` 필터, 선택한 핀과 팝업이
없는 상태를 표시한다. 지도 이미지, 구역별 배치도, 핀 위치와 안내 정보를 미리
등록해야 한다.

재학생존 혼잡도는 지도에 표시하지 않는다. 혼잡도나 만석 상태에 따라 지도 핀 또는
구역 색상을 변경하는 기능도 제공하지 않는다.

### 지도 구성과 조작 기본안

- 전체 지도는 디자인팀이 제작한 축제 전체 일러스트 지도를 사용한다.
- 각 구역에는 실제 배치를 표현한 별도 상세 지도를 제공하고 올해 전달된 주점·
  플리마켓·부스 배치도를 반영한다.
- 개발자가 지도 이미지, 구역, 핀 종류·위치와 이용 안내를 직접 등록·수정한다.
- 전체 지도는 확대·축소할 수 있다.
- 구역 상세 지도는 확대·축소하지 않고 장소와 배치를 읽기 좋은 크기로 표시한다.
- 가로로 긴 상세 지도는 스크롤바 없는 좌우 스크롤을 제공한다.

위 조작은 현재 기본안이다. 최종 일러스트와 가독성에 따라 프런트엔드·디자인팀이
확대·축소·스크롤 방식을 조정할 수 있으며, 확정하면 이 명세도 함께 갱신한다.

### 전체 지도와 구역 이동

전체 지도에는 등록된 장소 핀과 별도의 구역 이동 핀을 표시한다. 구역 이름표로
진입하지 않는다.

구역 이동 핀은 `주점 / 플리마켓 / 부스 / 대운동장 / 푸드트럭 / 호수공원`이다.
선택하면 정보 팝업 없이 해당 구역 상세 지도로 바로 이동한다. 일반 장소 핀은 현재
지도 위에 간단한 정보 팝업을 연다.

구역 상세 지도에서 뒤로 가면 전체 지도의 위치·확대 상태를 초기화하고 `전체` 필터,
선택 핀과 팝업이 없는 기본 화면으로 돌아간다.

### 핀 필터

- 전체 지도와 모든 구역 상세 지도에 제공한다.
- 아래 핀 분류의 대분류와 하위 종류를 기준으로 하되 현재 지도에 실제 존재하는 종류만
  선택지에 표시한다.
- 기본값 `전체`는 현재 지도의 모든 핀을 표시한다.
- 특정 종류를 선택하면 해당 핀만 남기고 나머지를 숨긴다.
- 한 번에 한 종류만 선택하며 다른 종류를 선택하면 기존 선택을 해제한다.
- 지도나 구역을 바꾸면 해당 지도에 맞는 필터 목록으로 바꾸고 `전체`로 초기화한다.

### 핀 정보 팝업

| 핀 대상 | 표시 정보 | 연결 버튼 |
|---|---|---|
| 개별 부스·주점·플리마켓 | 이름, 운영 시간, 간단한 소개 | `상세 보기` |
| 화장실·흡연구역·쓰레기통 | 간단한 위치 안내 | 없음 |
| 무대·게이트·티켓부스·인포메이션 | 이름, 위치, 등록된 이용 안내 | 없음 |
| 개별 푸드트럭·호수공원 내 장소 | 이름, 위치, 등록된 이용 안내 | 없음 |

팝업은 지도 위 하단에 표시한다. 등록되지 않은 정보는 해당 영역을 숨긴다. 바깥을
선택하면 닫으며 별도 닫기 버튼은 표시하지 않는다. 개별 부스·주점·플리마켓의
`상세 보기`만 해당 BOOTH-001 상세 화면으로 이동한다.

### 다른 기능과의 연결

- 부스·주점·플리마켓 상세의 위치 버튼은 해당 구역 상세 지도로 바로 이동해 대상
  핀이 보이는 위치를 표시하고 핀 선택·정보 팝업 상태로 연다.
- 지도 팝업에서 상세로 이동한 뒤 뒤로 돌아오면 기존 지도 위치, 필터, 선택 핀과
  팝업을 유지한다.
- 외부인 티켓의 `티켓존 위치 확인하기`는 앱 내 지도에서 외부인 티켓존을 중심으로
  표시하고 강조한다.
- 다른 기능의 위치 버튼으로 진입하면 일반 전체 지도 초기화보다 대상 장소 표시를
  우선한다.

다른 하단 메뉴에서 지도에 다시 들어오면 전체 지도 기본 상태로 초기화한다.

### 데이터 재사용과 오류

이미 조회한 지도·장소 정보를 재사용해 불필요한 재조회를 줄이고, 한 번 불러온 지도
이미지를 반복 사용해 연결 불안정에 대비한다. 구체적인 캐시 저장소와 만료 방식은 이
기능 명세에서 정하지 않는다.

| 상황 | 처리 |
|---|---|
| 핀·상세 정보 조회 실패 | 지도 이미지는 유지하고 실패 안내와 해당 정보 재시도 제공 |
| 지도 이미지 표시 실패 | `지도를 불러오지 못했어요.`와 `다시 시도` 표시 |
| 재시도 성공 | 정상 지도 또는 정보 표시 |

`다시 시도`를 선택하면 불러오지 못한 이미지 또는 정보만 다시 조회한다.

핀 정보 조회에 실패해도 위치를 식별할 수 있도록 지도·배치도 이미지 자체에 장소명 또는
번호를 표시한다. 장소명·번호의 구체적인 표기 방식과 시각 디자인은 디자인팀과 협의한다.

### 현재 핀 분류안

아래 분류는 현재 기획 기준이며 실제 운영과 배치 확인 뒤 바뀔 수 있다.

| 대분류 | 하위 핀 종류 | 상태 |
|---|---|---|
| 총학생회 관련 | 인포메이션, 유니폼 마켓 | 실제 위치·명칭 확인 필요 |
| 체험 | 플리마켓, 주점, 브랜드·서포터즈 부스, 행사 부스 | 실제 참여 목록에 따라 등록 |
| 체험 내 행사 부스 | 피크닉존, 포토부스 | 피크닉존 운영 여부·포토부스 위치 확인 필요 |
| 편의 시설 | 화장실, 흡연구역, 쓰레기통 | 실제 설치 위치 확인 필요 |
| F&B | 푸드트럭, 주류제휴부스 | 실제 운영 위치 확인 필요 |
| 공연 | 티켓부스, 입장게이트, 공연장, 공연장 게이트, 재학생존, 외부인존 | 실제 입장 동선 확인 필요 |

입장게이트와 공연장 게이트는 동일 장소인지 확인하기 전까지 구분한다.

### 현재 위치 구역안

이 표는 유추를 포함하며 올해 배치 자료와 총학생회 확인 결과에 따라 조정한다.

| 위치 구역 | 표시 대상 | 구역 상세 지도 연결 |
|---|---|---|
| 학생복지관 앞 민주광장 | 인포메이션, 유니폼 마켓, 플리마켓 | 플리마켓 핀 |
| 호수공원 | 포토부스 후보 위치, 행사 부스 | 호수공원 핀 |
| 체대 앞 | 푸드트럭, 주점, 흡연구역, 화장실, 주류제휴부스 | 푸드트럭·주점 핀 |
| 학술정보관과 제4공학관 사이 | 브랜드·서포터즈 부스, 흡연구역, 화장실 | 부스 핀 |
| 제1공학관 앞 | 티켓 수령 부스 | 장소 핀의 안내 팝업 |
| 대운동장 | 공연장·무대, 재학생존, 외부인존, 공연장 게이트 | 대운동장 핀 |

`체대`의 확인된 풀네임은 `예체능대학`이지만 이 구역의 최종 사용자 노출명은 아직
확정하지 않았으므로 최신 기능 명세의 `체대 앞`을 그대로 유지한다.

### 후속 확인

- 최종 전체·구역 지도 디자인, 구역 구분, 핀 위치와 조작 방식
- 포토부스 위치, 피크닉존 운영 여부와 편의 시설 실제 위치
- 입장게이트와 공연장 게이트의 동일 장소 여부
- 유니폼 마켓과 굿즈샵 판매처의 동일 장소 여부
- 티켓 수령 부스와 외부인 티켓존의 동일 장소 여부
- 유니폼 마켓·주류제휴부스·재학생존·외부인존 등의 팝업 문구와 동작
