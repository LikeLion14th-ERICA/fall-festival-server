# 지도

[위키 홈](../README.md) · 읽는 때: 해당 화면·데이터·API 변경

- 축제 전용 일러스트 지도 위에 마커를 표시. 실제 지도 자산, 사용 권한, 수정 범위는
  운영 자료로 관리
- 구역 필터와 카테고리 필터
- 마커 선택 시 라벨 및 하단 바텀시트
- 바텀시트 의도: 아이콘, 카테고리, 이름, 운영 시간, 설명, 위치
- 부스 상세의 `지도에서 위치 보기`는 해당 마커로 이동
- 지도를 사용할 수 없는 이용자를 위해 동일 장소를 찾을 수 있는 목록·텍스트 경로 제공

## 지도 분류

### 카테고리 — 확정 목록 15종

1. 인포
2. 총학생회 부스
3. 브랜드 부스
4. 플리마켓
5. 주점
6. 티켓부스
7. 화장실
8. 흡연구역
9. 의무실
10. 피크닉존
11. 푸드트럭
12. 이벤트존 (호수공원)
13. 포토부스
14. 쓰레기통
15. 공연장 (공연장 게이트 포함)

`매표소`, `티켓부스`, `티켓 수령 부스`는 같은 물리적 장소다. 지도에 좌표가 같은
중복 장소를 만들지 않는다. 대표 UI 명칭과 이 장소가 구역 필터인지 단일 마커인지는
결정 대기다.

### 구역 — 확인된 한국어 풀네임 반영

- 학생복지관 앞 민주광장 (플리마켓)
- 호수공원 이벤트존
- 호수공원 앞 피크닉존
- 예체능대학 앞 & 학술정보관 옆 주차장 (푸드트럭 & 주점)
- 학술정보관과 제4공학관 사이 (부스)
- 티켓 수령 부스
- 대운동장

Figma의 `호공 & 피크닉존` 표현과 달리 `호수공원 이벤트존`과 `호수공원 앞
피크닉존`은 별도 구역이다. Figma의 `체대앞 · 학정 옆 주차장`, `학정 ~ 4공 사이`
등 약칭은 사용자 노출 시 위 풀네임으로 바꾼다.

### 확인된 학교 용어

| 약칭 | 확인된 한국어 풀네임 | 영어·중국어 공식 표기 |
|---|---|---|
| 호공 | 호수공원 | 결정 대기 |
| 학정 | 학술정보관 | 결정 대기 |
| 4공 | 제4공학관 | 결정 대기 |
| 체대 | 예체능대학 | 결정 대기 |

`민주광장`은 띄어쓰기 없이 표기한다.

## 데이터 원칙

- 일러스트 지도를 채택한 경우 비율 좌표를 특정 `mapVersion`, 원본 크기, 실제
  콘텐츠 bounds, marker anchor에 묶는다. 일반 지도 좌표와 한 marker에서 섞지 않는다.
- 지도 자산 교체·crop·투명 여백 변경 시 새 버전과 검증된 좌표를 함께 게시한다.
- area와 category는 다른 축이며 필터 조합 규칙을 명시한다.
- `FestivalSpace`와 `MapMarker` 관계의 소유자와 cardinality를 하나로 정한다.
- 지도에는 목록 또는 텍스트 대체 경로를 제공한다.
- 지도 자산과 마커가 서로 다른 version인 상태는 공개하지 않는다. 게시 실패 시 직전의
  일관된 version을 유지한다.

## 구현 규칙

- 지도 카테고리와 구역의 원문 목록은 이 페이지의 지도 분류를 따른다.
- 일러스트 지도의 `xRatio/yRatio` 좌표는 특정 지도 자산 버전, 실제 콘텐츠 경계,
  마커 anchor에 묶고 `0..1` 범위를 검증한다. 일반 지도 좌표와 섞지 않는다.
- 구역과 카테고리는 서로 다른 분류 축이다. 필터의 선택 수와 AND/OR 규칙은 API가
  반환하는 현재 지도 설정을 따르고 클라이언트에 별도 기본값을 두지 않는다.
- 마커 선택, 바텀시트, 부스 상세의 `지도에서 위치 보기`는 동일한 안정적 marker ID를
  사용한다.
- 지도만으로 정보를 숨기지 말고 접근 가능한 목록·텍스트 경로를 유지한다.
- `의무실`은 지도 카테고리에 포함한다.
- `매표소`, `티켓부스`, `티켓 수령 부스`는 같은 물리적 장소다. 별도 좌표를 중복
  생성하지 않으며 대표 UI 명칭과 구역·마커 분류는 결정 후 고정한다.
- 지도 카테고리의 `공연장`은 공연장 게이트를 포함한 공연장 전체를 뜻한다. 게이트를
  독립 최상위 카테고리로 다시 분리하지 않는다.
- 지도 자산을 교체할 때는 새 map version을 발행하고 좌표 검증을 거친 뒤 원자적으로
  전환한다. 자산과 마커 revision이 다른 상태를 공개하지 않는다.
