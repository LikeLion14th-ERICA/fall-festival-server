# 학교 용어와 운영 데이터

[위키 홈](../README.md) · 읽는 때: 학교 명칭·구역·번역·운영 예시 변경

- 사용자가 확인한 공식 한국어 풀네임은 `호공 → 호수공원`, `학정 → 학술정보관`,
  `4공 → 제4공학관`, `체대 → 예체능대학`이다.
- 사용자 노출 기본 표기는 풀네임을 사용한다. 약칭이 별도로 필요한 UX라면 제품
  책임자에게 확인한다.
- 공식 표기는 띄어쓰기 없는 `민주광장`이다.
- `호수공원 이벤트존`과 `호수공원 앞 피크닉존`은 별도 구역이다.
- 위 한국어 명칭을 근거 없이 영어·중국어로 번역하지 않는다.
- 위 용어를 추측한 영문 enum(`HOGONG_PICNIC`, `PE_PARKING`,
  `ENG4_ACADEMIC` 등)은 안정적 식별자로 사용하지 않는다.
- 학교 공간·조직·프로그램의 한·영·중 공식 표기는 사용자가 확인해 준 표기 또는
  학교가 승인한 자료만 사용한다.
- 실제 축제 날짜, 지도 이미지, 무대, 출연진, 운영 시간, 메뉴, 마커 좌표, 공지,
  외부 링크는 운영 데이터로 분리한다. 예시 값을 제품 코드에 고정하지 않는다.

## 확정 결정

- `호공`, `학정`, `4공`, `체대`의 풀네임은 각각 `호수공원`, `학술정보관`,
  `제4공학관`, `예체능대학`이다.
- 공식 표기는 `민주광장`이다.
- 호수공원 이벤트존과 호수공원 앞 피크닉존은 별도 구역이다.
- 매표소, 티켓부스, 티켓 수령 부스는 같은 물리적 장소다.
- 의무실은 지도 카테고리에 포함한다.
- 공연장은 게이트를 포함한 공연장 전체를 뜻한다.
