# 학교 용어와 운영 데이터

[위키 홈](../README.md) · 읽는 때: 기능명·학교 명칭·구역·번역·운영 예시 변경

## 기능과 화면 표기

| 구분 | 현재 표기 |
|---|---|
| 하단 메뉴 | 홈, 굿즈샵, 공연, 부스&마켓, 지도 |
| 공연 내부 탭 | 라인업, 타임테이블 |
| 라인업 분류 | 아티스트, 콘테스트 |
| 부스&마켓 분류 | 전체, 부스, 플리마켓, 주점 |
| 티켓 메뉴 | 외부인 티켓 |
| 앱 내부 공지 목록 | 알림 메시지 |
| 공연장 관람 구역 | 재학생존, 외부인존 |
| 학교 소개 외부 연결 | 에리카 웰컴 데이 |

기존 `입장 티켓` 표기는 `외부인 티켓`으로 바꾼다. 에브리타임·카카오톡은 총학생회
공식 채널 구성에 포함하지 않는다.

## 지도 위치 표기 상태

사용자가 확인한 공식 한국어 풀네임은 `호공 → 호수공원`, `학정 → 학술정보관`,
`4공 → 제4공학관`, `체대 → 예체능대학`이다. 사용자 화면에는 풀네임을 사용하고
`민주광장`은 띄어쓰기 없이 쓴다.

최신 기능 명세의 위치 구역안은 다음과 같다. 이 표는 유추 사항을 포함하므로 올해 배치
자료와 총학생회 확인 전에는 확정 운영 데이터로 사용하지 않는다.

| 위치 구역 | 현재 연결 대상 |
|---|---|
| 학생복지관 앞 민주광장 | 인포메이션, 유니폼 마켓, 플리마켓 |
| 호수공원 | 포토부스 후보, 행사 부스 |
| 예체능대학 | 푸드트럭, 주점, 흡연구역, 화장실, 주류제휴부스 |
| 학술정보관과 제4공학관 사이 | 브랜드·서포터즈 부스, 흡연구역, 화장실 |
| 제1공학관 앞 | 티켓 수령 부스 |
| 대운동장 | 공연장·무대, 재학생존, 외부인존, 공연장 게이트 |

`입장게이트(공연장 입구)`와 `공연장 게이트`는 지도에서 하나의 `Place`로 모델링한다. `티켓 수령 부스`와
`외부인 티켓존`도 하나의 `Place`로 연결한다.

## 작성 원칙

- 학교 공간·조직·프로그램의 한·영·중·일 표기는 사용자가 확인한 표기나 학교 승인
  자료만 사용한다. 받은 영어·중국어 간체 번역은 [승인 번역표](translations.md)에 있다.
- 중국어는 최신 명세에서 중국어 간체로 정의한다. 준비가 완료되기 전에는 언어 목록에
  노출하지 않는다.
- 실제 축제 날짜, 지도 이미지, 무대, 출연진, 운영 시간, 메뉴, 마커 좌표, 공지,
  가격과 계좌는 운영 데이터로 구분한다.
- 최신 명세에서 임시 또는 확인 필요로 표시한 값을 제품 코드나 운영 콘텐츠에
  확정값으로 고정하지 않는다.
