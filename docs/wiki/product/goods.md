# 굿즈샵

[위키 홈](../README.md) · 읽는 때: 굿즈·색상·사이즈·판매 상태 변경

## GOODS-001 · 상품 정보와 판매 상태

하단 내비게이션의 `굿즈샵`에서 로그인 없이 축제 공식 굿즈의 사진·이름·가격과
색상·사이즈별 `구매 가능 / 품절` 상태를 확인한다. 앱은 **정보 조회만** 제공한다.
계좌·계좌번호 복사·토스 연결·송금·결제·주문·입금 확인·현장 지급 완료 상태는
제공하지 않는다.

### 상품 목록과 상세

- 목록에는 상품 이미지, 이름, 가격, 제공 색상·사이즈와 옵션별 판매 상태를 표시한다.
  정확한 남은 수량은 표시하지 않는다.
- 모든 실제 옵션이 품절이면 상품을 목록에서 제거하지 않고 `전체 품절`을 표시한다.
  하나 이상의 옵션이 다시 `구매 가능`이 되면 전체 품절을 해제한다.
- 상품 카드를 선택하면 상세에서 사진, 이름, 가격, 제공 색상·사이즈와 옵션별 상태를
  확인한다. 앱 안에서 옵션을 선택하거나 구매·송금을 진행하지 않는다.
- 최신 가격과 실제 제공 옵션은 관리자에게 등록된 공개 응답을 기준으로 한다. 이전
  기획안의 예시 가격을 운영값으로 사용하지 않는다.

### 상품과 판매 상태 관리

- [ADM-GOODS-002](admin/goods.md)에서 상품명·이미지·가격·색상·사이즈를 등록·수정한다.
- [ADM-GOODS-001](admin/goods.md)에서 실제 제공하는 색상·사이즈 조합마다
  `구매 가능 / 품절`을 저장한다. 수량 입력·증감 계산과 자동 품절 판정은 제공하지 않는다.
- 서로 다른 색상·사이즈 조합의 상태를 독립적으로 관리하며, 제공하지 않는 조합은
  표시하지 않는다. 옵션 삭제는 허용한다. 신규 상품·옵션의 최초 상태는 `구매 가능`이다.
- 관리자 저장 성공 후 목록과 상세의 상태를 새로고침 없이 반영한다. 화면이 보이는
  동안 15초 HTTP polling을 사용하고, 진입·앱 재활성화·온라인 복귀 때 즉시 조회한다.
  숨김·오프라인에서는 중단하고 실패하면 30초, 60초로 backoff하며 마지막 정상 상태를
  유지한다.

### 오류

판매 상태 조회에 실패하면 `재고 정보를 불러오지 못했어요.`와 `다시 시도`를 표시한다.
재시도에 성공하면 최신 상태를 표시한다. 정보가 없거나 가격이 확인되지 않았으면
임의의 값으로 대체하지 않는다.

2026-09-28 사용자 결정에 따라 이전의 계좌 안내·현장 송금 흐름은 공개 범위에서
제외했다. 기존 운영 계좌 설정과 이력의 보존 여부는 별도 데이터 운영 결정이다.
