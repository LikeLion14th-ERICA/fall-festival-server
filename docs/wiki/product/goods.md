# 굿즈샵

[위키 홈](../README.md) · 읽는 때: 굿즈·색상·사이즈 재고·현장 송금 변경

## GOODS-001 · 굿즈샵

하단 내비게이션의 `굿즈샵`에서 로그인 없이 축제 공식 굿즈의 상품 정보와 색상·사이즈별
구매 가능 여부를 확인하고 현장 구매용 송금 안내를 이용한다. 관리자가 상품 정보와
상품별 사이즈 판매 상태를 등록해야 제공할 수 있다.

기본 흐름은 `상품 목록 → 상품 상세 → 현장에서 실제 상품·옵션 확인 → 계좌 안내 →
외부 송금 → 담당자 송금 확인 → 현장 지급`이다.

### 상품 목록

- 상품 이미지, 상품명, 가격, 제공 색상·사이즈와 상품별 사이즈의 `구매 가능 / 품절`을
  표시한다. 정확한 남은 수량은 표시하지 않는다.
- 모든 관리 대상 사이즈가 `품절`이어도 목록에서 상품을 제거하지 않고 `전체 품절`을
  표시한다.
- 상품 카드를 선택하면 상세 화면으로 이동한다.
- 현재 구성 외에 관리자가 상품을 추가할 수 있다.

최신 명세의 현재 상품 구성은 다음과 같다.

| 상품명 | 가격 | 제공 사이즈 |
|---|---:|---|
| 야구 유니폼 | 37,000원 | S / M / L / XL / 2XL |
| 축구 유니폼 | 37,000원 | S / M / L / XL / 2XL |
| 바람막이 | 49,000원 | S / M / L / XL / 2XL |

실제 색상 이름과 이미지는 운영 자료로 준비한다.

### 상품 상세

- 상단에 두 색상의 상품 사진을 동시에 표시한다.
- 상품명, 가격, 제공 사이즈와 사이즈별 `구매 가능 / 품절`을 표시한다.
- 앱 안에서 색상이나 사이즈를 선택하는 기능은 제공하지 않는다. 실제 옵션은 현장
  담당자와 직접 확인한다.
- `계좌 확인하기` 버튼 위에 `현장에서 상품과 색상, 사이즈를 확인한 후 송금해 주세요.`를
  표시한다.
- `계좌 확인하기`를 선택하면 해당 상품의 계좌·송금 안내 화면으로 이동한다.

### 계좌와 현장 송금

계좌 안내에는 상품명·가격, 은행명·계좌번호·예금주와 현장 송금·수령 절차를 표시한다.
모든 굿즈는 같은 총학생회 계좌를 사용한다.

- `토스로 송금하기`는 토스 송금 화면으로 이동한다.
- `계좌번호 복사`는 계좌번호만 복사하며 사용자는 사용하는 은행 앱에서 직접 송금한다.
- 현장 담당자가 실제 상품·색상·사이즈 재고와 사용자의 송금 내역을 확인한 뒤 상품을
  즉시 지급한다.
- 앱은 상품·재고 조회와 송금 안내만 담당하며 입금 확인이나 상품 지급 완료 상태를
  자동 처리하지 않는다.

실제 은행명·계좌번호·예금주는 총학생회 전달 후 반영한다.

### 상품과 재고 관리

- 별도 관리자 페이지에서 상품명, 이미지, 가격, 색상, 사이즈를 등록·수정한다.
- [ADM-GOODS-001](admin-goods.md)은 상품별 등록된 사이즈의 `판매중 / 품절`만
  관리한다. 수량 입력·관리와 색상별 독립 재고 관리는 이 명세에 포함하지 않는다.
- 관리자 `판매중`은 사용자 `구매 가능`, `품절`은 사용자 `품절`로 반영한다.
- 상품 정보 등록·수정은 별도 기능이며 ADM-GOODS-001에는 가격·이미지·상품명·계좌
  수정과 결제·송금 확인을 포함하지 않는다.
- 명세의 S / M / L / XL은 조건부 예시다. 상품에 실제 등록된 사이즈만 관리하며
  기존 상품 구성의 2XL을 일괄 삭제하지 않는다.
- 관리자 수정 후 목록과 상세의 상태를 새로고침 없이 자동 반영한다. 구체적인 통신
  방식은 이 기능 명세에서 정하지 않는다.
- 재고 변경에 따른 앱 내 옵션 선택 해제는 없다. 계좌 버튼도 재고 변화만으로
  비활성화하지 않는다.

### 오류와 현장 유의사항

재고 조회에 실패하면 `구매 가능 / 품절` 대신 `재고 정보를 불러오지 못했어요.`와
`다시 시도` 버튼을 표시한다. 재시도에 성공하면 최신 재고 상태를 표시한다.

담당자가 수동으로 갱신하므로 앱 표시와 실제 재고가 다를 수 있고, 사용자가 현장 확인
전에 계좌를 보고 먼저 송금할 수도 있다. 선송금한 상품·옵션이 품절된 경우의 상품 변경
또는 환불 정책은 총학생회가 별도로 확정해야 한다.
