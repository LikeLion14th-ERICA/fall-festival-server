# 공개 내비게이션

[위키 홈](../README.md) · 읽는 때: 홈 진입·탭·라우팅 변경

고정 하단 내비게이션은 다음 5개다.

1. 홈
2. 굿즈샵
3. 공연
4. 부스&마켓
5. 지도

`공연` 안에서 `라인업 / 타임테이블` 탭을 전환한다. 라인업과 타임테이블을 별도 하단
메뉴로 만들지 않는다. 모든 하단 메뉴는 로그인 없이 접근한다.

- 공연으로 새로 진입하면 라인업 탭과 해당 시점의 기본 날짜·`아티스트` 분류를 표시한다.
- 부스&마켓으로 새로 진입하면 `전체` 분류와 목록 맨 위를 표시하되 별 저장값은 유지한다.
- 지도로 새로 진입하면 전체 지도, `전체` 필터, 선택 핀·팝업이 없는 상태를 표시한다.
- 부스·주점·플리마켓 상세나 외부인 티켓의 위치 확인 버튼으로 지도에 들어오면 전체
  지도 초기화보다 해당 장소 표시 규칙을 우선한다.
- 상세 화면에서 뒤로 돌아오는 흐름처럼 기능 문서가 별도 복귀 상태를 정한 경우에는
  위 초기 상태보다 해당 기능의 복귀 규칙을 우선한다.
