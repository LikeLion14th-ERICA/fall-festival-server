# 관리자 공지 목록

[위키 홈](../README.md) · [관리자 기능 목차](admin.md) · 읽는 때: 관리자 공지 목록·등록·수정 진입 변경

## 공지 목록 조회

ADM-NOTICE-001 · 관리자 공지 목록 관리

기능 기본 정보

| 항목 | 명세 내용 |
| --- | --- |
| 기능 ID | ADM-NOTICE-001 |
| 기능명 | 관리자 공지 목록 관리 |
| 기능 목적 | 등록된 공지를 목록으로 확인하고 공지 등록·수정·삭제 기능으로 진입한다. |
| 진입 경로 | 관리자 웹페이지 → 공지 관리 |
| 사용 대상과 권한 | 관리자 페이지 접근 권한이 있는 총학생회 운영자 |
| 실행 조건 | 관리자 페이지 접근 권한이 있는 사용자가 공지 관리 화면에 진입한 상태 |
| 기본 표시 정보 | 공지 유형, 제목, 최종 수정 시간, 수정 버튼, 삭제 버튼 |
| 정렬 기준 | 최종 수정 시간 기준 최신순 |
| 조회 범위 | 등록된 전체 공지 |
| 관련 기능 | ADM-NOTICE-002 공지 등록·수정 / ADM-NOTICE-003 공지 삭제 |

## 1. 공지 목록 조회

| 항목 | 규칙 |
| --- | --- |
| 화면 진입 | 공지 관리 화면 진입 시 등록된 공지 목록을 자동 조회한다. |
| 조회 대상 | 삭제되지 않은 전체 공지를 조회한다. |
| 공지 유형 | 각 공지의 유형을 `일반 / 분실물` 중 하나로 표시한다. |
| 제목 | 등록된 공지 제목을 표시한다. |
| 최종 수정 시간 | 해당 공지가 마지막으로 저장된 시각을 표시한다. |
| 최초 등록 공지 | 등록 후 한 번도 수정되지 않은 경우 최초 등록 시각을 최종 수정 시간으로 사용한다. |
| 정렬 | 최종 수정 시간이 가장 최근인 공지부터 상단에 표시한다. |
| 새 공지 작성 | `새 공지 작성` 선택 시 ADM-NOTICE-002 공지 등록 화면으로 이동한다. |
| 검색 및 필터 | 별도의 검색 및 공지 유형 필터 기능은 제공하지 않는다. |
| 페이지네이션 | MVP에서는 별도 페이지네이션 없이 등록된 전체 공지를 조회한다. |

## 2. 최종 수정 시간 규칙

| 항목 | 규칙 |
| --- | --- |
| 최초 등록 | 공지 등록 성공 시 등록 시각을 최종 수정 시각으로 저장한다. |
| 공지 수정 | 수정 저장 성공 시 최종 수정 시각을 해당 저장 성공 시각으로 갱신한다. |
| 시간 생성 기준 | 서버에서 등록 또는 수정 저장이 성공한 시각 |
| 시간 기준 | KST(Asia/Seoul) |
| 정렬 기준 | 서버에 저장된 최종 수정 시각 기준 |
| 수정 실패 | 최종 수정 시각을 갱신하지 않는다. |

## 3. 공지 등록 진입

| 동작 | 처리 |
| --- | --- |
| `새 공지 작성` 선택 | ADM-NOTICE-002 공지 등록 화면으로 이동 |
| 등록 화면 초기값 | 신규 등록 상태로 진입하며 기존 공지 데이터는 표시하지 않는다. |
| 등록 성공 후 | 공지 목록 화면으로 이동하고 최신 공지 목록을 다시 조회한다. |
| 등록된 공지 위치 | 등록 시각이 가장 최근이므로 목록 최상단에 표시한다. |

## 4. 공지 수정 및 삭제 진입

| 동작 | 처리 |
| --- | --- |
| `수정` 선택 | 해당 공지의 데이터를 조회한 후 ADM-NOTICE-002 공지 수정 화면으로 이동한다. |
| 수정 화면 초기값 | 기존 공지 유형, 제목, 본문, 이미지, 템플릿 정보를 초기값으로 표시한다. |
| 수정 성공 후 | 공지 목록 화면으로 이동하고 최신 공지 목록을 다시 조회한다. |
| 수정된 공지 위치 | 수정된 최종 수정 시각을 기준으로 목록 순서를 다시 정렬한다. |
| `삭제` 선택 | 공지를 즉시 삭제하지 않고 ADM-NOTICE-003 삭제 확인 절차를 실행한다. |
| 삭제 성공 후 | 삭제된 공지를 목록에서 제거하고 최신 공지 목록을 다시 조회한다. |
| 삭제 취소 | 기존 목록 상태를 유지한다. |

## 5. 목록 화면 동작 규칙

| 항목 | 규칙 |
| --- | --- |
| 수정 진입 | 각 공지의 `수정` 버튼을 통해서만 수정 화면으로 이동한다. |
| 삭제 진입 | 각 공지의 `삭제` 버튼을 통해 삭제 확인 절차를 시작한다. |
| 제목 선택 | 제목 또는 목록 행 자체를 선택해도 별도의 동작은 발생하지 않는다. |
| 목록 정렬 변경 | 관리자가 임의로 정렬 순서를 변경하는 기능은 제공하지 않는다. |
| 화면 재진입 | 다른 화면에서 공지 목록 화면으로 돌아오면 서버의 최신 공지 목록을 다시 조회한다. |
| 데이터 기준 | 관리자 화면에 임시로 저장된 데이터가 아닌 서버에 정상 저장된 공지 데이터를 기준으로 표시한다. |

## 6. 로딩 및 빈 목록 처리

| 상황 | 처리 |
| --- | --- |
| 목록 조회 중 | 공지 목록 영역에 로딩 상태를 표시한다. |
| 조회 완료 | 조회된 공지 목록을 최종 수정 시간 기준 최신순으로 표시한다. |
| 등록된 공지 없음 | 목록 영역에 `등록된 공지가 없습니다.`를 표시한다. |
| 빈 목록 상태 | `새 공지 작성` 기능은 정상적으로 사용할 수 있다. |

## 7. 예외 상황 및 오류 처리

| 상황 | 대응 |
| --- | --- |
| 공지 목록 조회 실패 | 공지 목록 대신 오류 상태를 표시한다. |
| 조회 실패 안내 문구 | `공지 목록을 불러오지 못했습니다. 다시 시도해주세요.` |
| 재조회 | 오류 상태에서 `다시 시도`를 선택하면 공지 목록 조회를 다시 요청한다. |
| 재조회 성공 | 서버의 최신 공지 목록으로 갱신한다. |
| 재조회 실패 | 오류 상태를 유지한다. |
| 수정 대상 공지 조회 실패 | 수정 화면으로 이동하지 않고 오류 안내를 표시한다. |
| 다른 관리자에 의한 변경 | 이후 목록 재조회 시 서버의 최신 데이터를 기준으로 표시한다. |

## 8. 완료 기준

| 확인 항목 | 완료 기준 |
| --- | --- |
| 목록 조회 | 관리자가 등록된 전체 공지 목록을 확인할 수 있다. |
| 공지 유형 | 각 공지가 `일반 / 분실물` 유형으로 구분되어 표시된다. |
| 제목 표시 | 각 공지의 제목이 정상적으로 표시된다. |
| 수정 시간 | 공지의 최종 저장 시각이 표시된다. |
| 최초 등록 시간 | 수정 이력이 없는 공지는 등록 시각을 최종 수정 시각으로 표시한다. |
| 정렬 | 최종 수정 시간이 최근인 공지부터 상단에 표시된다. |
| 등록 진입 | `새 공지 작성`을 통해 공지 등록 화면으로 정상 진입할 수 있다. |
| 수정 진입 | `수정`을 통해 해당 공지 데이터를 불러온 수정 화면으로 진입할 수 있다. |
| 삭제 진입 | `삭제` 선택 시 즉시 삭제하지 않고 삭제 확인 절차가 실행된다. |
| 목록 갱신 | 등록·수정·삭제 성공 후 최신 공지 목록이 다시 조회된다. |
| 빈 목록 | 공지가 없는 경우 `등록된 공지가 없습니다.`가 표시된다. |
| 조회 실패 | 목록 조회 실패 시 오류 문구와 `다시 시도` 기능이 표시된다. |
| 재조회 | 재조회 성공 시 최신 공지 목록으로 갱신된다. |
