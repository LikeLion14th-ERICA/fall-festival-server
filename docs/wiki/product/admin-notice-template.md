# 관리자 공지 템플릿

[위키 홈](../README.md) · [관리자 기능 목차](admin.md) · 읽는 때: 공지 템플릿·사전 번역 변경

### ADM-NOTICE-004 · 관리자 공지 템플릿 선택

| 항목 명세 | 내용 |
| --- | --- |
| 기능 ID | ADM-NOTICE-004 |
| 기능명 | 관리자 공지 템플릿 선택 |
| 기능 목적 | 자주 사용하는 공지와 번역문을 사전에 등록해두고, 관리자가 공지 작성 시 불러와 빠르게 작성할 수 있도록 지원 |
| 진입 경로 | 관리자 웹페이지 → 공지 관리 → 공지 등록·수정 → `공지 템플릿 선택` |
| 사용 대상과 권한 | 관리자 페이지 접근 권한이 있는 총학생회 운영자 |
| 기본 구성 | 사전 등록된 템플릿 목록 / 한국어 제목·본문 / 언어별 번역문 |
| 템플릿 사용 여부 | 선택 사항 / 템플릿 없이 공지 직접 작성 가능 |
| 관련 기능 | ADM-NOTICE-002 관리자 공지 등록·수정 / HOME-002 언어 변경 |

### 1. 템플릿 구성 및 번역 기준

| 항목 | 규칙 |
| --- | --- |
| 템플릿 내용 | 한국어 제목·본문과 사전에 작성된 언어별 번역문으로 구성 |
| 작성 주체 | 공지 템플릿과 번역문은 운영 측에서 사전에 작성 |
| 지원 언어 | 현재 사용자 웹에서 제공 준비가 완료된 언어 기준 |
| 번역 우선순위 | 영어 우선 / 중국어·일본어는 실제 제공 언어에 따라 준비 |
| 영어 번역 | 다국어 공지로 사용하는 템플릿에는 영어 번역 필수 |
| 미지원 언어 | 아직 사용자 웹에서 제공하지 않는 언어는 필수 입력 대상에서 제외 |

### 2. 템플릿 선택 및 적용

| 상황 | 처리 |
| --- | --- |
| 템플릿 선택 | 해당 템플릿의 제목·본문·언어별 번역문을 작성 화면에 불러옴 |
| 적용 후 수정 | 불러온 한국어 및 번역 내용을 관리자가 직접 수정 가능 |
| 다른 템플릿 선택 | 현재 템플릿에서 불러온 내용을 새 템플릿 내용으로 변경 |
| 템플릿 미선택 | 제목·본문을 직접 입력하여 공지 작성 가능 |
| 템플릿 목록 | 사전에 등록되어 사용 가능한 템플릿만 표시 |

### 3. 공지 작성 및 저장

| 순서 | 처리 |
| --- | --- |
| 1 | 관리자가 공지 작성 화면에서 템플릿 선택 여부 결정 |
| 2 | 템플릿 선택 시 제목·본문·번역문 자동 입력 |
| 3 | 필요한 경우 불러온 내용을 직접 수정 |
| 4 | 공지 등록 시 입력값 및 번역 데이터를 함께 저장 |
| 5 | 저장 성공 시 사용자 웹에서 사용할 수 있는 공지 데이터로 반영 |

- 템플릿은 **작성 편의를 위한 초기값**이며, 템플릿 원본과 실제 등록된 공지는 별개의 데이터로 관리한다.
- 템플릿 내용을 수정하여 공지를 등록하더라도 사전에 저장된 **원본 템플릿 자체는 변경하지 않는다.**

### 4. 번역문 처리 규칙

| 상황 | 처리 |
| --- | --- |
| 템플릿에 번역문 존재 | 해당 언어 번역문을 작성 화면에 함께 표시 |
| 관리자가 번역문 수정 | 수정된 번역문을 해당 공지의 번역 데이터로 저장 |
| 특정 언어 번역문 없음 | 해당 언어 번역값 없이 불러오고 기존 다국어 공지 정책에 따라 처리 |
| 템플릿 없이 직접 작성 | 일반 공지 등록·수정 기능의 번역 처리 규칙 적용 |
| 사용자 웹 반영 | 저장된 언어별 번역문을 사용자 웹의 언어 변경 기능에서 사용할 수 있도록 전달 |

### 5. 예외 상황 및 오류 처리

| 상황 | 대응 |
| --- | --- |
| 템플릿 목록 조회 실패 | 템플릿 기능을 사용할 수 없음을 안내하되 공지 직접 작성은 가능 |
| 템플릿 불러오기 실패 | 작성 중인 내용을 유지하고 직접 작성 가능 |
| 일부 번역문 없음 | 존재하는 번역문만 불러오고 없는 언어는 빈 상태 유지 |
| 오류 후 재시도 | 관리자가 템플릿을 다시 선택하여 불러오기 재시도 가능 |

오류 안내:

`공지 템플릿을 불러오지 못했습니다. 직접 작성하거나 다시 시도해주세요.`

### 6. 완료 기준

| 확인 항목 | 완료 기준 |
| --- | --- |
| 템플릿 조회 | 관리자가 사용 가능한 공지 템플릿 목록 확인 가능 |
| 템플릿 적용 | 선택한 템플릿의 제목·본문·번역문을 작성 화면에 불러올 수 있음 |
| 내용 수정 | 템플릿 적용 후 각 내용을 직접 수정 가능 |
| 템플릿 변경 | 다른 템플릿 선택 시 새 템플릿 내용으로 정상 변경 |
| 직접 작성 | 템플릿 없이도 공지 작성 가능 |
| 원본 보호 | 템플릿 적용 후 내용을 수정해도 원본 템플릿에는 영향 없음 |
| 번역 연동 | 저장된 번역 데이터를 사용자 웹의 언어별 공지 표시에 사용할 수 있음 |
| 오류 처리 | 템플릿 오류가 발생해도 공지 직접 작성 가능 |
