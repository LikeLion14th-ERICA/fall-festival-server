# 에리카 웰컴 데이

[위키 홈](../README.md) · 읽는 때: 홈 웰컴 데이 메뉴·학교 소개 외부 페이지 연결 변경

## WELCOME-001 · 에리카 웰컴 데이

축제를 방문한 고등학생에게 외부 페이지로 학교 소개 자료를 제공한다. 방문 고등학생을
주요 대상으로 하되 로그인 없이 누구나 이용한다. 기능 동작은 명세되었으며 학교 소개
자료와 연결 페이지는 준비 대기 상태다.

### 화면과 이동

- 홈 화면에 `에리카 웰컴 데이` 메뉴를 표시한다.
- 메뉴를 선택하면 확정된 외부 학교 소개 URL을 새 탭으로 연다.
- 기존 탭에는 축제 앱 화면을 유지한다.
- 학교 소개 자료는 외부 페이지에서 제공하며 앱 내부 별도 상세 화면은 만들지 않는다.
- 외부 페이지 준비와 연결 URL 확정이 실행 조건이다.

### 자료 준비와 공개 조건

| 항목 | 상태와 담당 |
|---|---|
| 학교 소개 자료 | 수령 예정, 실제 제공 담당자와 전달 일정 확인 필요 |
| 콘텐츠 구성 | 제공받은 자료를 바탕으로 기획팀에서 확정 |
| 외부 페이지 형식 | 자료 수령 후 결정 |
| 연결 URL | 외부 페이지 준비 후 확정 |
| 공개 전 확인 | 최종 콘텐츠, URL, 공개 접근 권한과 모바일 가독성 확인 |

자료·URL을 임의로 정하거나 미완성 페이지를 공개하지 않는다. 남은 결정은
[결정 대기 목록](decisions.md)의 WELCOME-001에서 추적한다.

### 완료 기준

- 홈 메뉴 선택 시 확정된 학교 소개 페이지가 새 탭에서 열린다.
- 기존 축제 앱 탭을 유지한다.
- 외부 페이지에 로그인 없이 접근할 수 있고 모바일에서 자료를 정상 조회할 수 있다.
- 공개 전에 최종 콘텐츠와 연결 URL 확인을 마친다.
