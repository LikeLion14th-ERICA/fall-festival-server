# 제품 개요

[위키 홈](../README.md) · 읽는 때: 최초 프로젝트 숙지 또는 제품 범위 변경

한양대학교 ERICA 가을 축제 현장 방문자가 필요한 정보를 빠르게 확인하고 현장 기능을
이용하는 모바일 우선 웹 서비스다. 일반 사용자는 설치·로그인·회원가입 없이 모든 공개
기능을 이용한다.

`LikeLion14th-ERICA/fall-festival-server`는 이 서비스의 Spring Boot 백엔드 저장소다.
루트 프로젝트가 서비스 서버이며 `test/`는 별도 실기기 검증 환경이다. 검증용 코드의
동작을 제품 요구사항으로 간주하지 않는다.

## 공개 기능 구성

- [홈](home.md): 재학생존 혼잡도, 언어, 최신 공지와 바로가기, 스탬프투어·외부인
  티켓 진입, 총학생회 공식 채널
- [에리카 웰컴 데이](welcome.md): 외부 학교 소개 페이지 연결, 자료·URL 준비 후 공개
- [굿즈샵](goods.md): 상품 정보, 사이즈별 구매 가능 여부와 현장 송금 안내
- [공연](lineup.md): 라인업·출연진 상세와 [타임테이블](timetable.md)
- [부스&마켓](spaces.md): 부스·주점·플리마켓 목록, 상세, 별 저장, 공유와 지도 연결
- [지도](map.md): 전체·구역별 일러스트 지도, 핀 필터와 장소 정보
- [알림 메시지](notice.md), [스탬프투어](stamp.md), [외부인 티켓](ticket.md)

기능별 확정 정도와 보류 항목은 [공개 범위와 기능 상태](scope.md), 아직 결정하지 않은
사항은 [결정 대기 목록](decisions.md)을 따른다.

## 제품 원칙

- 사용자가 가장 빨리 알아야 할 정보는 현장 혼잡도, 공연 일정, 장소, 부스 정보,
  최신 운영 안내다.
- 같은 기기·브라우저에 유지한다고 명시된 언어, 별, 스탬프 상태 외에는 사용자 계정이나
  로그인 기반 상태를 만들지 않는다.
- `새로고침 없이 반영`은 기능 요구사항이다. WebSocket, SSE, polling 등 통신 방식은
  이 문서에서 확정하지 않는다.
- 실제 축제 날짜, 운영 시간, 계좌, 지도 이미지·핀, 출연진, 부스 목록 같은 운영
  데이터는 최신 명세에서 확정된 값과 임시·확인 필요 값을 구분한다.
- 혼잡한 행사장과 불안정한 모바일 네트워크를 정상 운영 조건으로 보고 마지막 정상
  정보 유지, 빈 상태와 재시도 등 각 기능에 명시된 실패 동작을 제공한다.

관리자 기능은 [관리자 목차](admin.md)에서 혼잡도, 공지 목록·삭제·템플릿, 상품별
사이즈 판매 상태 관리로 구분한다.
