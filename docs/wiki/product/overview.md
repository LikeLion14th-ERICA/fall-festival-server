# 제품 개요

[위키 홈](../README.md) · 읽는 때: 최초 프로젝트 숙지 또는 제품 범위 변경

- 한양대학교 ERICA 가을 축제의 현장 방문자가 행사 정보를 빠르고 정확하게 확인하는
  모바일 우선 웹 서비스
- 재학생뿐 아니라 외부 방문자, 고등학생 견학 방문자, 영어·중국어 사용자 지원
- 일반 사용자는 설치·로그인·회원가입 없이 공개 정보를 조회
- 혼잡한 행사장, 불안정한 모바일 네트워크, 운영 중 콘텐츠 변경과 트래픽 급증에서도
  핵심 정보 제공을 유지
- 핵심 과업:
  - 지금 진행 중인 공연·이벤트 확인
  - 시간과 장소 확인
  - 부스·주점·플리마켓 및 메뉴 확인
  - 지도에서 시설·부스 찾기
  - 최신 운영 공지 확인

FigJam 최상위에는 `학교 축제 PWA`라고 쓰여 있지만 설치 가능성, 오프라인 캐시,
푸시 알림의 제공 여부와 동작은 결정 대기다. 일반 웹 캐시와 장애 시 제한적 읽기 기능은
PWA 채택 여부와 별개의 운영 요구다.

## 구현 기준

- 이 제품은 한양대학교 ERICA 가을 축제 현장에서 실제 운영되는 방문자용 웹 앱이다.
- 현재 Figma의 390×844 모바일 화면을 기준으로 모바일 우선으로 설계한다. 지원
  viewport, 브라우저, OS 조합은 출시 기준에 명시하고 해당 환경에서 검증한다.
- 일반 사용자는 로그인이나 회원가입 없이 모든 공개 기능을 이용할 수 있어야 한다.
- 고려해야 할 방문자군은 재학생, 외부 방문자, 고등학생 견학 방문자,
  영어·중국어 사용자다.
- 사용자가 가장 빨리 알아야 할 것은 `지금 진행 중인 것`, `언제 열리는지`,
  `어디에 있는지`, `부스에서 무엇을 제공하는지`, `운영 공지`다.
- 행사장 혼잡 시간대의 트래픽 급증, 느리거나 불안정한 모바일 네트워크, 운영 중
  일정·장소 변경을 정상적인 운영 조건으로 보고 설계한다.
