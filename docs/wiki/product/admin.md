# 관리자 기능

[위키 홈](../README.md) · 읽는 때: 관리자 기능 범위·관련 제품 문서 확인

관리자 페이지 접근 권한이 있는 총학생회 운영자가 사용하는 별도 웹페이지다.
권한은 [보안 규칙](../engineering/security.md)에 따라 서버에서 검증한다.
기능 명세 반영은 구현 완료나 배포 완료를 의미하지 않는다.

| 기능 ID | 담당 문서 | 연동 대상 |
|---|---|---|
| ADM-CROWD-001 | [혼잡도 조회·변경](admin-crowd.md), [데이터·반영·검증](admin-crowd-state.md) | [홈](home.md), [지도](map.md), 별도 운영 시간 관리 |
| ADM-NOTICE-001 | [공지 목록](admin-notice.md) | 등록·수정·삭제 진입 |
| ADM-NOTICE-002 | 등록·수정 상세 명세 대기 | 목록의 진입·복귀와 템플릿 연동만 정의됨 |
| ADM-NOTICE-003 | [공지 삭제](admin-notice-delete.md) | [홈](home.md), [알림 메시지](notice.md), 기존 상세 주소의 삭제 콘텐츠 차단 |
| ADM-NOTICE-004 | [공지 템플릿](admin-notice-template.md) | 등록·수정, [언어 변경](home.md#home-002--언어-변경) |
| ADM-GOODS-001 | [굿즈 재고](admin-goods.md) | [굿즈샵](goods.md) |

첨부 명세에는 ADM-NOTICE-002 본문이 없다. 제목·본문 입력 제한, 이미지 업로드,
직접 작성 번역 처리, 저장 검증 등 누락된 세부 동작을 임의로 확정하지 않는다.
운영 시간 관리와 상품 정보 관리도 별도 기능이며 이번 관리자 기능에 합치지 않는다.
남은 항목은 [결정 대기](decisions.md)에 기록한다.

관리자 공지 목록은 삭제되지 않은 전체 공지를 최종 수정 시각 최신순으로 조회한다.
사용자 목록의 노출 기간·등록 시각 정렬과 구분한다. 신규 공지 알림 버튼 정책과 별개로
삭제 성공한 공지는 사용자 새로고침 없이 최대 5초 이내 제거한다.
