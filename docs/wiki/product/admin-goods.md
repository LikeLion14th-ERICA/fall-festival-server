# 관리자 굿즈 재고 관리

[위키 홈](../README.md) · [관리자 기능 목차](admin.md) · 읽는 때: 상품별 사이즈 판매 상태 변경

## ADM-GOODS-001 · 관리자 굿즈 재고 관리

| 항목 명세 | 내용 |
| --- | --- |
| 기능 ID | ADM-GOODS-001 |
| 기능명 | 관리자 굿즈 재고 관리 |
| 기능 목적 | 관리자가 굿즈의 사이즈별 판매 상태를 변경하고 사용자 웹의 굿즈샵에 반영 |
| 진입 경로 | 관리자 웹페이지 → 굿즈 재고 관리 |
| 사용 대상과 권한 | 관리자 페이지 접근 권한이 있는 총학생회 운영자 |
| 관리 단위 | 상품별 사이즈 |
| 관리 상태 | `판매중 / 품절` |
| 재고 수량 | 입력 및 관리하지 않음 |
| 관련 기능 | GOODS-001 굿즈샵 |

### 1. 상품 및 사이즈별 상태 확인

| 항목 | 규칙 |
| --- | --- |
| 상품 구분 | 등록된 굿즈별로 재고 상태를 구분하여 표시 |
| 표시 정보 | 상품명 / 사이즈 / 현재 판매 상태 |
| 사이즈 | 해당 상품에 등록된 판매 사이즈 표시 |
| 상태 | 각 사이즈별 `판매중 / 품절` 표시 |
| 수량 | 실제 남은 재고 수량은 표시하거나 입력하지 않음 |

현재 관리 대상 사이즈가 `S / M / L / XL`인 경우 해당 사이즈만 표시한다.

### 2. 재고 상태 변경

| 순서 | 처리 |
| --- | --- |
| 1 | 관리자가 관리할 굿즈를 확인 |
| 2 | 사이즈별 현재 `판매중 / 품절` 상태 확인 |
| 3 | 변경할 사이즈의 상태 선택 |
| 4 | 변경된 상태 저장 |
| 5 | 저장 성공 시 사용자 웹의 해당 굿즈 재고 상태에 반영 |

### 3. 상태 변경 규칙

| 항목 | 규칙 |
| --- | --- |
| 판매 상태 | 각 사이즈는 `판매중 / 품절` 두 상태만 사용 |
| 품절 처리 | `판매중` 상태를 `품절`로 변경 가능 |
| 품절 해제 | `품절` 상태를 다시 `판매중`으로 변경 가능 |
| 개별 관리 | 각 사이즈 상태는 서로 독립적으로 변경 |
| 상품 간 관리 | 한 상품의 재고 변경은 다른 상품의 상태에 영향 없음 |
| 저장 기준 | 저장이 완료된 상태만 실제 재고 상태로 적용 |

### 4. 사용자 웹 반영

| 항목 | 규칙 |
| --- | --- |
| 반영 대상 | 변경한 상품의 사이즈별 판매 상태 |
| 반영 시점 | 관리자 저장 성공 후 사용자 웹에 자동 반영 |
| 판매중 | 사용자 웹에서 해당 사이즈를 구매 가능한 상태로 처리 |
| 품절 | 사용자 웹에서 해당 사이즈를 품절 상태로 처리 |
| 전체 품절 | 해당 상품의 모든 관리 대상 사이즈가 `품절`이면 전체 품절 상태로 판단 |

※ 사용자 화면에서 품절 상태를 **어떤 문구·디자인으로 보여주는지**는 `GOODS-001 굿즈샵` 명세를 따른다.

### 5. 관리 범위

| 관리 항목 | 포함 여부 |
| --- | --- |
| 사이즈별 판매중/품절 변경 | 포함 |
| 재고 수량 입력 | 미포함 |
| 상품 가격 수정 | 미포함 |
| 상품 이미지 수정 | 미포함 |
| 상품명 수정 | 미포함 |
| 계좌 정보 관리 | 미포함 |
| 결제 및 송금 확인 | 미포함 |

상품 정보 자체의 등록·수정이 필요한 경우 재고 관리와 별도의 관리자 상품 관리 기능으로 분리한다.

### 6. 예외 상황 및 오류 처리

| 상황 | 대응 |
| --- | --- |
| 상태 변경 실패 | 변경 전 상태 유지 |
| 저장 실패 | 사용자 웹에도 변경 사항을 반영하지 않음 |
| 중복 요청 | 상태 변경 처리 중 동일 항목의 중복 저장 요청 방지 |
| 오류 메시지 | `품절 상태를 변경하지 못했습니다. 다시 시도해주세요.` |
| 재시도 | 오류 발생 후 관리자가 다시 상태 변경 가능 |

### 7. 완료 기준

| 확인 항목 | 완료 기준 |
| --- | --- |
| 상태 조회 | 상품별 사이즈의 현재 판매 상태 확인 가능 |
| 품절 처리 | 판매중 상태를 품절로 변경 가능 |
| 품절 해제 | 품절 상태를 판매중으로 다시 변경 가능 |
| 개별 변경 | 각 사이즈를 독립적으로 관리 가능 |
| 수량 미관리 | 별도의 실제 재고 수량 입력 없이 상태만 관리 |
| 자동 반영 | 저장 성공 후 사용자 웹 재고 상태에 반영 |
| 전체 품절 | 모든 관리 대상 사이즈 품절 시 전체 품절 상태 판단 가능 |
| 오류 처리 | 저장 실패 시 기존 상태 유지 및 오류 안내 |
