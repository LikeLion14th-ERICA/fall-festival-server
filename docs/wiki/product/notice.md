# 알림 메시지

[위키 홈](../README.md) · 읽는 때: 앱 내부 공지 목록·노출 기간·새 공지 동작 변경

## NOTICE-001 · 알림 메시지 목록

축제 공지의 상세 내용을 별도 상세 페이지나 펼치기 없이 한 화면에서 연속해서 확인하는
공개 목록이다. [HOME-003](home.md)의 최신 공지 제목 또는 `전체보기`를 선택하면 목록
맨 위로 진입한다.

### 목록과 공지 표시

- 최초 등록 시각이 최신인 순서로 세로 배치하고 전체 내용은 스크롤로 읽는다.
- 각 공지에는 전체 제목, 제목 아래 `MM.DD HH:mm` 형식의 등록 시각, 회색 배경 영역의
  본문과 공지 사이 가로 구분선을 표시한다.
- 본문은 텍스트와 링크로 구성한다. 이미지는 직접 표시하지 않고 연결 링크로 대체한다.
- 본문 링크는 새 탭에서 열어 기존 알림 메시지 탭을 유지한다.
- 별도 상세 화면과 접기·펼치기 동작은 제공하지 않는다.

### 노출 기간과 언어

| 구분 | 노출 규칙 |
|---|---|
| 일반 공지 | 한국 시간 기준 당일 등록분만 표시 |
| 지난 일반 공지 | 날짜가 바뀌면 사용자 목록에서 제외 |
| 분실물 공지 | 등록 날짜와 관계없이 계속 표시 |
| 통합 정렬 | 당일 일반 공지와 분실물 공지를 합쳐 최초 등록 시각 최신순 |
| 언어 | 사용자가 선택한 언어의 번역이 완료된 공지만 표시 |

한국어 공지는 한국어 저장에 성공하면 외국어 번역 완료 여부와 관계없이 먼저 게시한다.
영어·중국어 간체·일본어 중 번역이 준비 중이거나 실패한 언어에서는 해당 공지를
표시하지 않으며 다른 언어로 대체하지 않는다. 번역이 완료되면 해당 언어와 날짜·유형
조건을 모두 만족하는 경우에만 표시한다.

공지 수정 시 최초 등록 시각은 유지하고 최종 수정 시각만 바꾼다. 사용자 정렬과
[HOME-003](home.md)의 최신 공지 선정은 최초 등록 시각을 기준으로 하므로, 수정만으로
공지 순서를 바꾸거나 지난 일반 공지를 다시 노출하지 않는다.

분실물 회수 현황은 공지에 연결된 외부 링크 안에서 관리한다. 회수 완료를 이유로 앱
공지 자체를 숨기는 기능과 일차별 선택 탭은 추가하지 않는다. 과거 데이터 삭제는 이
기능의 범위가 아니며 사용자 노출 종료와 구분한다.

### 열람 중 새 공지

목록을 읽는 중 새 공지가 제공돼도 현재 내용과 스크롤 위치를 바로 바꾸지 않는다.
화면 제목 바로 아래에 `새 공지가 있어요` 버튼을 고정해 표시하며 스크롤 중에도
유지한다. 버튼을 선택하면 최신 목록을 반영하고 맨 위로 이동한 뒤 버튼을 숨긴다.

메인의 HOME-003은 새 제목을 자동 반영하지만 이 목록은 사용자가 버튼을 선택한 뒤
반영한다. 한국 시간 00:00에 날짜가 바뀌면 전날 일반 공지는 목록에서 제외한다.

### 빈 상태와 오류

| 상황 | 처리 |
|---|---|
| 표시 대상 공지 없음 | 목록 영역에 `등록된 공지가 없어요` 표시 |
| 최초 조회 실패 | 목록 영역에 `공지를 불러오지 못했어요` 표시 |
| 정상 조회 뒤 갱신 실패 | 마지막 정상 목록 유지 |

별도 오류 화면과 재시도 버튼은 제공하지 않는다.

### 관리자 연동과 삭제

[관리자 공지 목록](admin-notice.md)은 사용자 목록과 달리 전체 미삭제 공지를 최종
수정 시각 최신순으로 조회한다. 사용자 등록 시각 정렬·노출 기간을 이에 맞춰 바꾸지 않는다.
[관리자 삭제](admin-notice-delete.md)가 서버에서 성공하면 홈·사용자 목록에서 최대
새로고침 없이 자동 제거한다. 삭제에는 `새 공지가 있어요` 선택을 기다리지 않는다.
삭제된 공지와 첨부 이미지는 더 이상 노출하지 않고 기존 상세 주소로도 내용을 제공하지
않는다. 삭제 실패 시 기존 노출을 유지하고, 사용자 갱신 실패 시 마지막 정상 상태를
유지하다 통신 복구 시 삭제를 반영한다.

ADM-NOTICE-003의 상세 주소·첨부 이미지 언급만으로 새 상세 화면이나 이미지 직접
표시를 추가하지 않는다. 기존 사용자 명세와의 화면 구성 정합성은 [결정 대기](decisions.md)다.
번역 템플릿은 [ADM-NOTICE-004](admin-notice-template.md)를 따른다.
