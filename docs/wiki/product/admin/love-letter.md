# 러브레터 운영 관리

## ADM-LOVE-001 · 사전 쪽지와 링크

운영자는 실제 참여자에게 확정 동의문으로 사전 동의를 받은 뒤 성별, 이름 또는 닉네임,
한 줄 내용, 연락처, 지정 참여일, 동의 확보 시각과 버전을 등록한다. 입력 원문이 담긴
파일을 저장소에 넣지 않는다. 등록 성공 시 생성된 일회용 링크 토큰은 한 번만 표시하며
해당 참여자에게 운영 채널로 전달한다. 재발급하면 이전 미사용 링크는 즉시 무효다.
이미 연결한 참여자의 링크를 재발급하지 않는다. 지정일이 지난 권리는 이월하지 않는다.

## ADM-LOVE-002 · 신고·차단·참여 제한

신고 목록은 대상 쪽지 ID, 신고자 ID, 시각으로 표시한다. 상세에는 처리에 필요한
작성자 ID와 쪽지 원문·연락처를 관리자에게만 보여 주고 열람을 감사한다. 신고만으로
자동 차단하지 않는다. 운영자는 쪽지를 차단해 추가 추첨과 기존 수신자의 연락처 열람을
막고, 작성자 또는 신고자를 행사 종료까지 각각 참여 제한할 수 있다. 잘못 제한한
참여자는 해제할 수 있다. 차단해도 당일 수신자에게 재추첨하지 않는다.

## ADM-LOVE-003 · 운영 설정과 중지

기간과 동의문 버전을 설정하면 기본 비활성이다. 참여자 생성 전까지만 설정을 변경한다.
남녀 초기 쪽지와 암호화 키가 모두 준비되어야 활성화할 수 있다. 중지 버튼은 신규 등록,
추첨, 공개 연락처 열람을 즉시 막는다. 중지는 기존 DB 삭제가 아니며 종료 7일 후
개인정보 정리는 별도로 수행한다. 운영 종료 후 새 사전 등록·링크 발급은 거절한다.

관리자 행위는 ADMIN 권한으로 보호한다. 상세 열람·등록·재발급·차단·제한·해제·설정
변경의 감사 이력에는 대상 ID와 행위만 남긴다. 원문과 링크 토큰은 감사·로그에 남기지 않는다.
