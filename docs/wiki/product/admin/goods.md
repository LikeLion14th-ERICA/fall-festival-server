# 관리자 굿즈

[위키 홈](../../README.md) · 읽는 때: 굿즈 판매 상태·상품·색상·사이즈 변경

관리자 굿즈 기능은 [GOODS-001](../goods.md)에 상품 정보와 옵션별 판매 상태를 제공한다.
실제 재고 개수, 입금 확인, 상품 예약과 지급 완료는 관리하지 않는다.

## ADM-GOODS-001 · 색상·사이즈별 판매 상태 조회 및 변경

### 관리 단위와 표시

- 상품별로 실제 제공하는 색상·사이즈 조합을 표시한다.
- 같은 사이즈라도 색상이 다르면 각각 독립적으로 관리한다.
- 실제 제공하지 않는 조합은 관리·사용자 표시 대상에서 제외한다.
- 담당자가 각 조합의 `구매 가능 / 품절`을 직접 선택한다.
- S/M/L/XL로 고정하지 않고 2XL을 포함한 상품별 등록 사이즈를 사용한다.
- 실제 수량의 입력·저장·증감 계산과 수량 값에 따른 자동 판정은 제공하지 않는다.

### 변경 규칙

1. 상품·색상·사이즈와 현재 판매 상태를 확인한다.
2. 현장 판매 가능 여부에 따라 대상 조합의 상태를 바꾸고 저장한다.
3. 저장 성공 시 대상 상태와 상품의 전체 품절 여부를 갱신한다.
4. 사용자 굿즈 목록과 상세에 새로고침 없이 반영한다.
5. 다시 판매할 수 있으면 `품절`에서 `구매 가능`으로 변경할 수 있다.

- 실제 제공 옵션이 모두 `품절`이면 `전체 품절`로 표시하되 상품은 목록에 유지한다.
- 하나 이상의 옵션이 `구매 가능`이면 전체 품절을 해제한다.
- 다른 옵션의 상태는 함께 바꾸지 않는다.
- 계좌 확인이나 송금만으로 판매 상태를 자동 변경하지 않는다.
- 현장 담당자가 실제 상품·옵션과 송금을 확인한 뒤 지급하며 선결제·예약은 제공하지
  않는다.
- 저장에 성공한 상태만 사용자 서비스에 적용한다.

| 상황 | 처리 |
|---|---|
| 등록 상품 없음 | `등록된 상품이 없습니다.`와 상품 등록 진입 제공 |
| 조회 실패 | `판매 상태를 불러오지 못했습니다. 다시 시도해주세요.`와 재시도 제공 |
| 저장 실패 | 기존 상태·전체 품절 여부 유지, `판매 상태를 변경하지 못했습니다. 다시 시도해주세요.` 표시 |

## ADM-GOODS-002 · 상품 및 제공 옵션 등록·수정

### 입력

- 상품 목록에서 등록된 상품명·가격·색상·사이즈를 확인하고 신규 등록이나 수정으로
  진입한다.
- 상품명, 0 이상의 원 단위 정수 가격, 사용자 목록·상세용 이미지, 실제 제공 색상과
  사이즈를 등록·수정한다.
- 공백만 있는 상품명과 잘못된 가격은 저장하지 않는다.
- 상품별로 서로 다른 색상·사이즈를 사용할 수 있고 실제 판매 조합만
  `ADM-GOODS-001` 관리 대상으로 연결한다.
- 두 색상 상품의 모습을 사용자 화면에 함께 표시할 수 있는 이미지 구성을 지원한다.
  이미지 필드 수·크기·배치는 최종 디자인에서 정하며 색상 선택에 따른 이미지 전환
  기능은 추가하지 않는다.
- 상품명·가격·실제 제공 색상·사이즈·조합은 저장에 필요하다. 이미지 입력 구성과 옵션 없는
  상품의 입력 방식은 미정이므로, 불완전한 상품을 사용자 서비스에 공개하지 않는다.

### 등록·수정 규칙

- 현재 상품 외의 신규 굿즈를 추가할 수 있다.
- 등록 성공 시 상품 목록에 추가하고 제공 옵션을 판매 상태 관리에 연결하며 사용자
  굿즈샵에 반영한다.
- 수정 성공 시 상품·옵션 정보를 갱신하고 그대로 유지된 옵션의 판매 상태는 보존한다.
- 상품명·가격만 바꿔도 기존 옵션 상태를 초기화하지 않는다.
- 신규 옵션의 최초 `구매 가능 / 품절` 상태는 아직 확정하지 않는다.
- 등록 후 색상·사이즈·실제 제공 조합의 삭제 정책은 미정이며 현재 목은 저장을 거절한다.
- 신규 옵션에 `0개` 같은 수량 데이터를 만들지 않는다.
- 모든 굿즈는 동일한 총학생회 계좌를 사용하며 상품별 계좌 관리 기능은 없다.
- 최종 상품 목록·가격·색상·사이즈·이미지는 총학생회 전달 자료를 기준으로 반영한다.

| 상황 | 처리 |
|---|---|
| 등록 상품 없음 | `등록된 상품이 없습니다.`와 신규 등록 진입 제공 |
| 조회 실패 | `상품 정보를 불러오지 못했습니다. 다시 시도해주세요.`와 재시도 제공 |
| 입력 오류 | 해당 항목 안내, 저장하지 않음 |
| 이미지 업로드 실패 | 실패 안내와 재시도, 수정 중에는 기존 이미지 유지 |
| 등록 실패 | 입력 유지, `상품을 등록하지 못했습니다. 다시 시도해주세요.` 표시 |
| 수정 실패 | 기존 상품·판매 상태와 입력 유지, `상품을 수정하지 못했습니다. 다시 시도해주세요.` 표시 |
