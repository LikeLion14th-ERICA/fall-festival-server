# 관리자 공지

[위키 홈](../../README.md) · 읽는 때: 공지 목록·작성·번역·삭제·템플릿 변경

관리자 공지는 [HOME-003](../home.md)과 [NOTICE-001](../notice.md)에 연결한다. 공지는
`일반 / 분실물`로 구분하고 이미지를 직접 업로드하지 않으며 필요한 자료는 외부 링크로
제공한다.

## ADM-NOTICE-001 · 관리자 공지 목록 조회

삭제되지 않은 전체 공지를 조회하고 작성·수정·삭제 기능으로 진입한다.

- 유형, 한국어 제목, 최초 등록 시각과 최종 수정 시각을 표시한다.
- 관리자 목록은 최종 수정 시각 최신순으로 정렬한다.
- 사용자 목록과 홈 최신 공지는 최초 등록 시각을 기준으로 정렬·선정한다.
- 지난 일반 공지도 관리자 목록에는 유지한다. 사용자 화면에서는 최초 등록일 당일에만
  표시하고 KST 00:00부터 제외한다.
- 분실물 공지는 날짜가 바뀌어도 사용자 화면에 유지하며 삭제하면 노출을 종료한다.
- 기존 공지를 수정해도 최초 등록 시각과 등록일은 유지하며 지난 일반 공지를 다시
  노출하지 않는다.

등록된 공지가 없으면 `등록된 공지가 없습니다.`를 표시한다. 조회 실패 시
`공지 목록을 불러오지 못했습니다. 다시 시도해주세요.`와 재시도를 제공한다.

## ADM-NOTICE-002 · 관리자 공지 등록·수정 및 번역

### 입력

- `일반 / 분실물` 중 유형을 선택한다.
- 한국어 제목과 본문은 필수이며 공백만 있으면 미입력으로 처리한다. 본문 줄바꿈은
  유지한다.
- 필요한 경우 외부 링크를 입력하고 웹 주소 형식을 검증한다. 사용자 화면에서 링크를
  선택하면 새 탭으로 연다.
- 이미지는 직접 첨부하지 않는다.
- 영어·중국어 간체·일본어의 제목·본문과 `준비 중 / 완료 / 실패` 상태를 확인한다.
- 준비된 번역이나 자동 번역 결과를 담당자가 확인·수정할 수 있다. 번역 제공자와
  처리 기술은 Product에서 정하지 않는다.
- 최초 등록·최종 수정 시각은 저장 성공 시 생성·갱신하며 담당자가 직접 입력하지 않는다.

### 신규 등록과 언어별 게시

1. 유형과 한국어 제목·본문, 필요한 링크를 입력하고 선택적으로 템플릿을 적용한다.
2. 저장 시 필수값과 링크 형식을 검증한다.
3. 한국어 저장에 성공하면 외국어 번역 여부와 관계없이 한국어 공지를 먼저 게시한다.
4. 번역이 완료된 언어는 날짜·유형 조건도 만족할 때 해당 언어 사용자에게 게시한다.
5. 준비 중이거나 실패한 언어에서는 해당 공지를 표시하지 않고 다른 언어로 대체하지
   않는다.
6. 번역 실패 언어는 재시도하거나 번역문을 직접 입력·수정할 수 있다.

영어 번역은 모든 공지의 준비 대상이다. 앱에서 실제로 제공 중인 언어만 사용자 노출
대상으로 삼고 준비 우선순위는 영어, 중국어 간체, 일본어 순이다.

### 수정

- 기존 유형·제목·본문·링크·번역문을 불러와 필요한 항목을 바꾼다.
- 저장 성공 시 최초 등록 시각은 유지하고 최종 수정 시각만 갱신한다.
- 저장 성공 내용과 언어별 게시 가능 상태를 사용자 홈·목록에 새로고침 없이 반영한다.
- 운영상 정정 안내는 기존 공지 수정이 아니라 새 공지 등록 방식을 사용한다.
- 게시 후 원문 수정에 따른 상세 재번역·전환 절차는 현재 추가 정의 범위가 아니다.

### 실패 처리

| 상황 | 처리 |
|---|---|
| 필수값 누락 | 해당 입력 안내, 저장하지 않음 |
| 링크 형식 오류 | 오류 안내 후 수정할 때까지 저장하지 않음 |
| 등록 실패 | 입력 유지, `공지를 등록하지 못했습니다. 다시 시도해주세요.` 표시 |
| 수정 실패 | 기존 게시 내용과 입력 유지, `공지를 수정하지 못했습니다. 다시 시도해주세요.` 표시 |
| 번역 실패 | 한국어 게시 유지, 실패 언어 표시와 재시도·직접 입력 제공 |
| 템플릿 조회 실패 | 직접 작성 가능 상태 유지 |

## ADM-NOTICE-003 · 관리자 공지 삭제

1. 삭제할 공지의 제목과 `이 공지를 삭제하시겠습니까?` 확인창을 표시한다.
2. 취소하면 요청 없이 기존 공지를 유지한다.
3. 삭제를 확인한 경우에만 삭제를 요청한다.
4. 성공하면 관리자 목록과 한국어·모든 번역 언어의 사용자 노출에서 제거한다.
5. 홈에 표시 중이던 공지라면 남은 노출 대상 중 최초 등록 시각이 가장 최근인 공지로
   바꾸고, 대상이 없으면 공지 없음 상태를 적용한다.

삭제 실패 시 기존 공지를 유지하고 `공지를 삭제하지 못했습니다. 다시 시도해주세요.`를
표시한다. 날짜 변경에 따른 일반 공지 노출 종료와 담당자 삭제는 구분한다.

## ADM-NOTICE-004 · 관리자 공지 템플릿 선택

사전에 준비한 공지 원문과 번역문을 불러와 현장 작성과 번역 대기를 줄인다.

- 템플릿 목록에는 준비된 이름을 표시한다.
- 선택하면 한국어 제목·본문과 준비된 영어·중국어 간체·일본어 번역문을 작성 화면에
  불러오며 필요한 항목을 수정할 수 있다.
- 원문을 그대로 쓰면 기존 번역문을 재사용하고 불필요하게 전체를 다시 번역하지 않는다.
- 게시 전 원문을 바꾸면 변경된 원문에 맞는 번역문을 준비하며 이전 번역을 그대로
  게시하지 않는다.
- 다른 템플릿을 선택하면 작성 항목을 새 템플릿 내용으로 교체하지만 원본 템플릿은
  변경하지 않는다.
- 템플릿 없이 직접 작성할 수 있다.
- 템플릿이나 일부 번역문이 없거나 조회·번역에 실패해도 한국어 직접 작성과 우선
  게시를 막지 않는다.
- 템플릿은 관리자 화면에서 만들지 않는다. 운영 측이 준비한 원문·번역문을 서버 운영자가
  JSON 파일로 전체 교체한다(README `공지 템플릿 교체`). 실제 템플릿을 받기 전까지는
  `템플릿 등록 필요` 임시 템플릿 하나만 제공한다.
- 공지는 시작한 템플릿 ID를 저장한다. 그 템플릿이 교체로 사라지면 공지 내용은 유지하고
  연결만 끊는다.
