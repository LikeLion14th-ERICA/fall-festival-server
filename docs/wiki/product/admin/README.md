# 관리자 Product 범위

[위키 홈](../../README.md) · 읽는 때: 관리자 기능 범위·공통 동작·제외 기능 판단

관리자 기능은 총학생회 현장 운영자가 별도 운영자 웹페이지에서 사용한다. 공개 사용자
서비스는 관리자 페이지와 관계없이 로그인 없이 이용한다. 담당자별 세부 권한·역할을
나누는 기능은 현재 Product 범위에 포함하지 않으며 인증 방식은 이 문서에서 정하지
않는다.

## 공통 기준

- 날짜와 시각은 한국 시간(KST)을 사용하고 날짜는 00:00에 바뀐다.
- 저장에 성공한 데이터만 사용자 서비스에 반영한다.
- 저장에 실패하면 기존에 정상 저장된 데이터와 시각을 유지한다.
- 혼잡도, 공지와 굿즈 판매 상태의 저장 성공 결과는 사용자 화면에 새로고침 없이
  반영한다. WebSocket, SSE, polling 등 통신 방식은 여기서 정하지 않는다.
- 실제 축제 일정·운영 데이터와 최종 문구는 총학생회 확정 자료를 반영한다.

## 관리자 범위 밖

- 재학생존 운영 시간: 확정 일정을 개발자가 등록·수정하며 관리자 시간 편집은 없다.
- 지도 혼잡도: 사용자 홈에만 혼잡도를 표시하며 지도와 연동하지 않는다.
- 공연 일정·라인업: 개발자가 직접 등록·수정하며 공연 관리자 기능 ID는 정의하지 않는다.
- 공연 안내: 반입 금지 물품 안내를 개발자가 직접 반영하며 관리자 게시 기능은 없다.
- 부스·주점·플리마켓 정보와 지도·구역·핀: 전달·확정 자료를 개발자가 직접 반영한다.
- 티켓·굿즈 입금 확인: 현장 담당자가 송금 화면을 직접 확인한다.
- 굿즈 실제 재고 수량: 저장하지 않고 옵션별 `구매 가능 / 품절`만 관리한다.
- 스탬프 상품 소진: 앱이나 관리자 페이지에서 관리하지 않고 현장에서 안내한다.
- 스탬프 상품 수령: 현장 담당자가 사용자 휴대폰의 수령 안내 창에 인증 코드를 직접
  입력하고 `확인`한다. 관리자 페이지에는 수령 버튼·코드 조회·코드 관리 기능을 두지 않는다.

각 기능의 사용자 노출 동작은 [Product 개요](../overview.md)와 연결된 사용자 기능 문서를
우선한다. API·DB·Entity·DTO 계약은 별도 동기화 작업에서 결정한다.
