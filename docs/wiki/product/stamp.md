## STAMP-001 · 스탬프투어 참여 및 상품 수령

로그인 없이 여러 부스를 체험하고 스탬프를 모아 멋사 부스에서 몬스터 상품을 받는
기능이다. [HOME-006](home.md) 또는 휴대폰 기본 카메라로 스탬프투어 QR을 스캔해
진입한다.

기본 흐름은 `START 선택 → QR로 4개 적립 → 멋사 부스 방문 → 담당자가 상품 수령
처리 → 몬스터 수령`이다. 하루 최대 4개를 적립하고 상품은 하루 1회만 받는다.

### 시작 화면

시작 화면에는 축제 정보, 스탬프투어 제목, 실제 행사 기간, START 버튼, 참여 방법,
지급·초기화·소진 조건과 몬스터 협찬 정보를 표시한다.

- START를 선택하면 당일 참여 시작 기록을 저장하고 수집 화면으로 이동한다.
- START만으로 스탬프를 적립하지 않는다. 첫 스탬프도 멋사 부스의 QR을 스캔해야 한다.
- `상품은 하루 1회 수령 가능`, 매일 밤 12시 초기화와 당일 수령 필요,
  `상품은 준비 수량 소진 시 지급이 종료됩니다`를 안내한다.
- 참여 순서는 멋사 부스에서 시작 QR로 1개 적립, 다른 부스 체험 뒤 운영자가 보여 주는
  QR 스캔, 총 4개 뒤 멋사 부스에서 상품 수령이다.
- `부스 돌고 몬스터 받자!`는 제안 문구이며 최종 디자인 문구가 아니다.

실제 행사 기간과 상품 수령 운영 시간은 확정 자료를 반영한다.

### 수집 화면과 버튼 상태

동일한 디자인의 스탬프 4칸과 `현재 적립 개수 / 4`를 표시한다. 유효 QR을 인식할
때마다 다음 빈칸에 1개를 표시하며 별도 성공 문구나 팝업은 제공하지 않는다.

| 당일 상태 | `QR 찍기` | 상품 버튼 |
|---|---|---|
| 0~3개·미수령 | 활성, 앱 내부 카메라 실행 | `상품 받으러 가기` 비활성 |
| 4개·미수령 | 비활성, 선택 동작 없음 | `상품 받으러 가기` 활성 |
| 4개·수령 완료 | 비활성 유지 | `오늘 상품 수령 완료` 비활성 |

상품 수령 뒤에도 스탬프를 차감하지 않지만 추가 적립과 추가 상품 수령은 불가능하다.
4칸이 모두 채워진 스탬프판과 `상품 수령 완료` 상태는 계속 표시한다.

### QR과 적립 규칙

- 모든 부스에서 동일한 QR과 동일한 식별값을 사용한다.
- 부스 운영자가 체험 완료 후 참여자에게 QR을 보여 주는 방향이다.
- 서로 다른 부스를 체험하고 부스별 하루 1회 적립하는 것이 운영 원칙이다.
- 시스템은 부스별 이력을 저장하거나 체험·중복 참여를 검증하지 않는다. 운영 원칙
  준수는 사용자 양심에 맡긴다.
- 당일 총 스탬프 개수만 관리하고 유효한 QR 인식 1회당 1개를 더한다.
- 한 번 인식하면 스캔을 종료해 앱 내부 카메라의 연속 인식만 막는다. 새로고침이나
  링크 재접속에 대한 별도 중복 방지는 적용하지 않는다.
- 4개에 도달하거나 상품을 받은 뒤에는 추가 적립하지 않는다.
- 부스별 고유 QR, 사용자별 QR, 계정 기반 적립, QR 서명·만료와 별도 서버 중복 검증을
  이 기능에 추가하지 않는다.

### QR 스캔 경로와 예외

| 경로·상황 | 처리 |
|---|---|
| 앱 내부 | `QR 찍기` → 카메라 허용 → 인식·1개 적립 → 카메라 종료 → 수집 화면 복귀 |
| 휴대폰 기본 카메라 | QR 연결 적립 페이지 진입 → 적립 처리 → 수집 화면 연결 |
| 카메라 미허용 | 적립 없이 기존 화면 유지, `QR을 찍으려면 카메라 접근을 허용해 주세요` 표시 |
| 스탬프투어 외 QR | 적립 없이 `스탬프투어 QR이 아니에요` 표시, 카메라를 유지해 재스캔 허용 |

기본 안내 경로는 앱 내부 `QR 찍기`다. 서로 다른 브라우저의 기록은 자동 합산하지
않는다. START 전에 기본 카메라로 QR 링크에 직접 들어온 경우의 시작 기록 처리는
아직 결정하지 않았다.

### 상품 수령

스탬프 4개를 모으고 아직 받지 않은 사용자가 `상품 받으러 가기`를 선택하면 수집
화면 위에 작은 안내 창을 연다.

- `이 화면을 멋사 부스 담당자에게 보여주세요.`를 표시한다.
- `상품 수령` 버튼은 담당자만 누르며, 사용자가 직접 누르면 수령 완료되어 상품을
  받지 못할 수 있음을 안내한다.
- 멋사 부스 담당자가 사용자 화면의 `상품 수령` 버튼을 직접 선택한다.
- 안내 바깥을 선택하면 처리 없이 닫고, 미수령 상태에서는 다시 열 수 있다.
- 처리하면 당일 수령 완료를 저장하고 창을 닫으며 상품 버튼을 비활성화한다.
- 앱에는 실시간 상품 소진 표시, 관리자 소진 설정과 소진에 따른 버튼 변경을 제공하지
  않는다. 소진 여부는 현장 부스에서 안내한다.

### 당일 기록과 초기화

같은 기기·브라우저에서는 당일 참여 시작 여부, 적립 개수와 수령 상태를 유지한다.
당일 START 기록이 있으면 시작 화면을 생략한다.

한국 시간 00:00에 시작 기록·스탬프 개수·수령 상태를 각각 시작 전·0개·미수령으로
초기화한다. 미사용 스탬프는 이월하지 않으며 다음 날 4개를 다시 모으면 상품을 하루
1회 받을 수 있다. 다음 진입에는 시작 화면을 표시하고 START를 선택한 뒤 0개 수집
화면에서 `QR 찍기`를 활성화하고 `상품 받으러 가기`를 비활성화한다.
