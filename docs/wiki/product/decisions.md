  안에서 연장해 현재 시각이 운영 구간으로 돌아오면 당일 혼잡도 상태·수정 시각을 복원한다.

## 2026-09-28 추가 사용자 확정 · 야간 운영

이 항목은 위 재학생존 운영 시간 결정의 종료 상한과 자정 뒤 선택·초기화 설명을 확장한다.

- `ADM-CROWD-002`: 시작은 운영일 당일, 종료는 시작 뒤부터 KST 익일 `01:00`까지 분 단위로
  저장한다. 종료 경계는 실제 운영 구간에서 제외하며, 익일 `01:01`은 `422`로 거절한다.
  운영 시간 PUT 경로의 날짜가 operatingDay이고 JSON 본문은 offset RFC3339 `opensAt`,
  `closesAt` 두 필드만 받는다. 초는 `:00` 필수이고 `.000`을 포함한 모든 소수초는 거절한다.
- 혼잡도 선택일은 KST 오늘 게시 일정이 시작된 뒤에는 오늘로 고정한다. 오늘 일정 시작 전에는
  전날 구간이 OPEN이면 전날을 선택하고, 그렇지 않으면 기존 오늘 이후 첫 게시일·최종일 fallback을
  사용한다. 오늘 일정과 전날 구간이 겹쳐도 오늘 일정을 우선하고 겹침 자체는 거절하지 않는다.
- 자정은 혼잡도 상태를 초기화하는 시점이 아니다. 전날 구간이 열려 있고 당일 일정이 아직
  시작되지 않았으면 전날 operatingDay, 단계, 수정 시각을 유지한다. 익일 `01:00` 경계부터는
  다음 선택 운영일의 상태를 보여 준다.
- 단계 PUT은 선택일이 오늘이거나 현재 OPEN일 때만 허용한다. 요청은 현재 관리자 GET의 ETag와
  idempotency key를 사용하며, 성공 재시도 범위는 선택 operatingDay별이다. 자정 전에 대기한
  요청의 선택일이나 표현이 달라지면 `409 EDIT_CONFLICT`를 반환한다.

## 2026-09-18 사용자 확정

- `BOOTH-001`: 부스&마켓 분류를 디자인의 여섯 개(`주점`, `부스`, `플리마켓`, `푸드트럭`,

  (`RESTROOM`, `PHOTO_BOOTH`, `SMOKING_AREA`, `TRASH_BIN`). 네 시설 밖의 장소 핀은 필터 없이
  `전체`에서만 보인다. 이전 대분류는 새 필터로 추측해 옮기지 않는다(V19).

  `예체능대학` 위치를 대체한다. `체대 → 예체능대학` 건물 표기는 그대로다.
- `HOME-001`, `ADM-CROWD-001`: 보통 안내 문구를 번역 자료·디자인에 맞춰
  `재학생존의 공간이 절반 이상 찼어요.`로 바꾼다(영어 `At least half full`, 중국어
  `已占用一半以上`). 영어·중국어 간체 번역은 [승인 번역표](translations.md)를 따른다.
- `TICKET`·`GOODS` 계좌 현재값은 catalog revision 밖의 운영 설정으로 둔다. 계좌 변경은
  HTTP 관리자 기능이 아닌 별도 DB role의 CLI만 사용한다.
- 계좌 변경은 한 명의 운영자가 dry-run, expected version, 끝 네 자리 확인, 작업자·사유·근거
  ID를 거쳐 적용한다. 빠른 현장 변경을 위해 2인 승인은 도입하지 않는다. 자격증명 유출이나
  작업 실수가 즉시 공개 계좌 변경으로 이어질 수 있으므로 trigger history, 최소 권한과
  사후 검토를 필수로 둔다.
