   기준은 무엇인가?
7. 고등학생 견학 프로그램의 공식 명칭, 대상, 안내 자료 제공 주체와 노출 시점은

10. 올해 공식 축제명, 행사 날짜, DAY 수는 무엇인가? Figma와 API 예시는 모두

## 기록 방법

새 질문은 관련 도메인, 상태, 근거, 질문을 함께 기록한다. 답변을 받으면 해당 도메인
페이지와 API 계약을 같은 변경에서 갱신하고, 해결한 질문은 확정 결정 또는 승인 근거로
옮긴다. 기술 계약의 존재와 운영 승인 여부를 구분한다.
