Figma는 Figma 플러그인으로 확인한다. Design의 `86:2`에는 390×844 기준 화면
1–16과 기능 요약 노트가 있고, FigJam의 `34:398`에는 사용자·관리자 IA가 있다.

### 결정 우선순위

1. 사용자의 최신 명시적 결정
2. 총학생회·학교 승인 자료
3. Figma IA·와이어프레임
4. API v1 계약

예를 들어 FigJam은 챗봇을 전역 플로팅으로 표현하지만 최신 확정안은 홈에서
진입하도록 했다. 이 경우 홈 진입을 따른다. API v1은 상위 결정을 실행 가능한 계약으로
표현하며 충돌이 생기면 같은 변경에서 바로잡는다.

## 에이전트 판단 규칙

결정의 우선순위는 다음과 같다.

1. 사용자가 대화에서 명시적으로 확정한 최신 결정
2. 총학생회·학교가 제공하거나 승인한 최신 공식 자료
3. Figma 서비스 IA와 와이어프레임의 정보 구조·화면 의도
4. [`핵심 기능 API 명세서 v1`](../../../핵심%20기능%20API%20명세서%20v1.md)의 계약

- 하위 자료가 상위 자료와 충돌하면 하위 자료를 그대로 구현하지 않는다. API 계약은
  상위 제품 결정과 일치하도록 같은 변경에서 갱신한다.
- 충돌 또는 미확정 사항은 [결정 대기 목록](../product/decisions.md)에 기록하고
  제품 책임자에게 질문한다.
- Figma와 API 예시의 날짜, 아티스트, 공연, 운영 시간, URL, 영문 enum은 실제 운영
  데이터가 아니라 placeholder다.
- Figma 자료는 Figma 플러그인으로 읽는다. 사용자가 별도로 요청하지 않는 한
  브라우저 자동화나 `computer-use`로 Figma를 열람하지 않는다.
