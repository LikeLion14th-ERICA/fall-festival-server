# 근거 자료와 충돌 처리

[위키 홈](../README.md) · 읽는 때: 최초 숙지, Figma 확인, 요구사항 충돌

현재 제품 요구사항의 기준은 사용자가 제공한 최신 `기능 명세서 사용자 v5`와
`기능 명세서 관리자 v5`, 그 이후 대화에서 명시적으로 확정한 결정이다. 이번
동기화에서 기존 제품 위키와 v5 명세가 다르면 v5를 따른다. 관리자 v5의 작업 과정
메모는 요구사항으로 복사하지 않고 확정된 기능과 범위 밖 결정만 사용한다.

보조 자료는 다음과 같다.

- 총학생회·학교가 제공하거나 승인한 최신 공식 자료

## 결정 우선순위

1. 사용자가 대화에서 명시적으로 확정한 최신 결정
2. 사용자가 제공한 최신 기능 명세서
3. 총학생회·학교가 제공하거나 승인한 최신 공식 자료
4. Figma IA·와이어프레임의 화면 의도
5. API v1 계약

최신 기능 명세서는 제품 동작의 기준이지만 `임시 기준`, `확인 필요`, `미정`, `후속
작업`을 확정값으로 바꾸지 않는다. 이후 사용자의 명시적 결정이나 승인 자료가 나오면
그 변경이 우선한다.

## 판단 규칙

- 하위 자료가 상위 자료와 충돌하면 하위 자료를 그대로 구현하지 않는다.
- 최신 명세에서 제외했다고 밝힌 화면·기능은 기존 문서나 Figma에 있어도 되살리지 않는다.
- 명세에 없는 요구사항, API, 저장소, 인증, 실시간 통신 방식은 추측해 추가하지 않는다.
- Figma와 문서 예시의 날짜·금액·운영 시간·장소·콘텐츠는 명시적으로 확정됐는지 먼저
  확인한다.
- 모호하거나 서로 맞지 않는 내용은 [결정 대기 목록](decisions.md)에 남기고 임의로
  하나를 선택하지 않는다.
- Figma는 Figma 플러그인으로 읽으며 사용자가 별도로 요청하지 않는 한 브라우저
  자동화로 열람하지 않는다.
- 제품 문서와 API 계약이 충돌하더라도 제품 문서 동기화 작업에서 API·코드까지 임의로
  수정하지 않는다. API 변경은 별도 범위와 검토를 거친다.
