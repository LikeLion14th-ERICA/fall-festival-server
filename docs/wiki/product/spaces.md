# 부스&마켓

[위키 홈](../README.md) · 읽는 때: 부스·주점·플리마켓 목록·상세·별·공유 변경

## BOOTH-001 · 부스&마켓

하단 내비게이션이나 공유받은 상세 링크에서 로그인 없이 부스·주점·플리마켓 정보를
확인하고 관심 항목 저장, 상세 링크 공유와 지도 위치 확인을 이용한다. 실제 목록과
상세 정보는 출시 전에 등록하며 멋사 부스도 목록에 포함한다.

### 목록과 분류

- 분류는 `전체 / 주점 / 부스 / 플리마켓 / 푸드트럭 / 총학생회 부스 / 프로모션 부스`다.
  최초 진입은 `전체`와 목록 맨 위다. `전체`는 모든 유형을 함께 표시한다.
- 분류를 바꾸면 새 목록의 맨 위로 이동한다. 목록 카드는 대표 사진, 이름과 위치를
  표시하며 카드 전체를 선택하면 상세로 이동한다.
- 축제 3일 동안 같은 목록을 제공한다. 날짜 선택과 검색 기능은 제공하지 않는다.
- 이름 가나다순으로 정렬하되 별로 저장한 항목을 위에 놓고, 저장·미저장 그룹 안에서
  각각 가나다순으로 정렬한다. 선택 분류에도 같은 규칙을 적용한다.
- 상세에서 돌아오면 분류와 스크롤 위치를 유지하고 변경된 별 상태로 다시 정렬한다.
  다른 하단 메뉴에서 돌아오면 `전체`와 목록 맨 위로 초기화하되 별 저장값은 유지한다.

### 상세

- 대표 사진 1장을 원본 비율로 채우고 중앙 기준으로 자른다. 크기는 디자인팀이 정한다.
- 이름·분류·운영 주체와 전달받아 등록된 운영 시간·위치·문의 SNS를 표시한다.
  값이 없으면 제목과 영역을 함께 숨긴다.
- 부스·총학생회·프로모션 부스는 소개와 체험·진행 이벤트를, 주점·푸드트럭은 소개와
  메뉴명·확정 가격을, 플리마켓은 간단한 설명을 표시한다. 없는 이벤트·메뉴 영역은
  숨긴다. 주점 메뉴는 개발자가 전달받은 정보를 직접 등록한다.
- 모든 상세 하단에 별 저장·공유·`지도에서 위치 보기`를 제공한다. 스탬프투어 참여
  여부는 상세 화면에 표시하지 않는다.
- **계좌·계좌번호 복사·토스 연결·송금·결제 기능은 제공하지 않는다.** 메뉴 가격은
  정보로만 표시하며, 가격이 미확정인 품목에 임의의 가격이나 합계를 만들지 않는다.

### 별 저장과 공유

빈 별을 선택하면 저장하고 채워진 별로 바꾸며, 다시 선택하면 해제한다. 저장 상태는
같은 기기·브라우저에서 유지하고 다른 환경과 동기화하지 않는다.

공유 버튼은 현재 상세 링크를 대상으로 한다. 지원 환경에서는 기기 공유창을 열고,
지원하지 않으면 상세 링크를 복사한다. 공유받은 링크는 로그인 없이 상세로 연결한다.

### 지도 연결

`지도에서 위치 보기`는 앱 내부 [MAP-001 지도](map.md)의 해당 구역으로 이동해 대상
위치를 중심으로 보여 주고 핀을 선택한 상태로 팝업을 연다. 팝업의 `상세 보기`는 이
상세 화면으로 돌아온다. 실제 지도 자산·핀은 프런트엔드가 관리한다.

### 정보 관리와 오류

개발자가 전달받은 이름·분류·사진·운영 주체·소개·운영 시간·위치·문의·이벤트·메뉴를
등록·수정한다. 발전협력팀 배치도의 세 칸이 같은 부스인지는 보류 상태이므로 승인
자료 전에는 임의로 합치거나 나누지 않는다.

| 상황 | 처리 |
|---|---|
| 목록에 등록된 항목 없음 | `등록된 정보가 없어요.` |
| 목록·상세 조회 실패 | `정보를 불러오지 못했어요.`와 `다시 시도` |
| 재시도 성공 | 정상 목록 또는 상세 표시 |

2026-09-28 사용자 결정으로 이전의 부스 계좌·송금 안내와 계좌 복사를 공개 범위에서
제외했다. 기존 운영 계좌 설정과 이력은 별도 데이터 운영 결정을 거쳐 정리한다.
