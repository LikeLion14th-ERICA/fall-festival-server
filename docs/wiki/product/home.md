# 홈

[위키 홈](../README.md) · 읽는 때: 홈 화면·공지 진입·언어·바로가기 변경

홈의 공개 기능은 `HOME-001`부터 `HOME-008`이다. 모두 로그인 없이 이용하며, 자료
대기·개발 보류 항목의 공개 조건은 [기능 범위](scope.md)를 따른다. `WELCOME-001`
에리카 웰컴 데이는 2026-09-22 결정으로 제거했다([웰컴 데이](welcome.md) 참조).

## HOME-001 · 재학생존 혼잡도 확인

메인 상단에서 재학생존의 혼잡 정도와 운영 상태를 보여 주어 공연장 출발 판단을
돕는다. 현장 운영자가 실제 인원을 집계하는 기능은 없으며 별도 관리자 페이지에서
관찰 결과에 따라 단계를 선택한다.

| 상태 | 운영자 판단 기준 | 기본 색상 | 선택 시 안내 |
|---|---|---|---|
| 여유 | 점유율 약 50% 수준 | 초록 | 재학생존의 공간이 많이 남았어요. |
| 보통 | 점유율 약 70% 수준 | 주황 | 재학생존의 공간이 절반 이상 찼어요. |
| 혼잡 | 점유율 약 85% 수준 | 빨강 | 재학생존이 많이 혼잡해요. |
| 만석 | 추가 입장 통제 시작 | 검정 | 재학생존이 꽉 차서 외부인존에서만 즐길 수 있어요. |

퍼센트는 운영자 판단에만 사용하고 사용자 화면에는 표시하지 않는다. 디자인 색상
코드는 디자인팀이 확정한다. 기본 화면에는 색상 동그라미와 상태명만 표시한다. 영역
전체를 선택하면 화면 위 작은 안내에 현재 상태의 문구와 시각을 표시하고, 안내 바깥을
선택하면 닫는다. 전체 단계 설명, 별도 페이지와 확인 버튼은 제공하지 않는다.

| 시점 | 기본 표시 | 선택 시 안내 | 시각 표시 |
|---|---|---|---|
| 당일 입장 시작 전 | 색상 없이 `운영 전` | 오늘 재학생존 입장은 {당일 입장 시작 시각}에 시작해요 | 없음 |
| 입장 시작 후 최초 수정 전 | 초록 `여유` | 여유 안내 | `운영 시작 기준` |
| 운영자 수정 후 | 선택한 색상·상태 | 해당 상태 안내 | `{HH:mm} 업데이트` |
| 당일 운영 종료 후 | 색상 없이 `운영 종료` | 오늘 재학생존 운영이 종료됐어요 | 없음 |

혼잡도 운영 시간은 현재 `published FestivalRevision`의 축제일별 `FestivalDay`에서
읽는다. 공개·관리자 응답은 게시된 `opensAt`·`closesAt`을 사용하며 관리자 페이지에는
운영 시간 편집 기능을 제공하지 않는다. 유효한 게시 일정이 없으면 API는
`503 CROWDING_SCHEDULE_UNCONFIGURED`를 반환한다.

- 종료 시각을 현재 시각보다 이전으로 변경하면 즉시 `운영 종료`로 바꾼다.
- 종료 뒤 시간을 연장해 다시 운영 시간이 되면 당일 운영자 입력 이력이 있을 경우
  마지막 단계와 수정 시각을 복원하고, 없으면 `여유`와 `운영 시작 기준`을 표시한다.
- KST 00:00에 전날 혼잡도와 수정 시각을 초기화한다. 다음 운영일로 이월하지
  않는다. 시작 전은 운영 전, 시작 후 수정 전은 여유다.
- 관리자 저장 성공 결과는 홈에 새로고침 없이 반영한다. 화면이 보이는 동안에는
  15초 HTTP polling을 사용하고, 진입·앱 재활성화·온라인 복귀 때 즉시 다시 조회한다.
  숨김·오프라인 상태에서는 중단하며 실패하면 마지막 정상값을 유지하고 30초, 60초로
  backoff한다. 같은 요청을 겹치게 보내지 않고 늦은 응답은 요청 세대 번호로 폐기한다.
  같은 `meta.revision`이어도 혼잡도는 시간 경계와 운영자 저장으로 바뀔 수 있으므로
  revision만으로 응답을 버리지 않는다. 지도에는 혼잡도를 표시하지 않는다.
- 최초 조회에 실패하면 색상 없이 `확인 불가`를 표시한다. 이를 선택하면
  `혼잡도 정보를 불러오지 못했어요. 잠시 후 다시 확인해 주세요`를 보여 준다.
- 정상 조회 뒤 갱신에 실패하면 마지막 정상 상태와 시각을 유지하고 다음 성공 때
  최신 정보로 바꾼다.

혼잡도는 사용자 홈에만 표시한다. 지도에는 혼잡도를 표시하지 않고 혼잡도나 만석
상태에 따라 지도 핀·구역 색상을 바꾸지 않는다.

## HOME-002 · 언어 변경

메인 상단에는 현재 언어명을 표시하는 버튼을 둔다. 최초 접속은 브라우저 언어와
관계없이 한국어다. 버튼을 선택하면 바로 아래에 목록을 펼치고 언어를 선택하면 즉시
적용한 뒤 닫는다. 바깥을 선택하면 변경 없이 닫으며 확인 버튼, 별도 페이지와 별도
로딩 표시는 두지 않는다.

| 언어 | 목록 표시명 | 준비 우선순위 |
|---|---|---|
| 한국어 | 한국어 | 기본 제공 |
| 영어 | English | 외국어 1순위 |
| 중국어 간체 | 中文 | 외국어 2순위 |
| 일본어 | 日本語 | 외국어 3순위 |

번역, 언어 전환 구현, 폰트·크기·자간·줄바꿈·넘침 디자인 점검이 모두 끝난 언어만
목록에 원어 이름으로 표시한다. 일정이 부족하면 영어부터 중국어 간체, 일본어 순으로
추가할 수 있다.

- 이미지에 포함된 글자를 제외한 앱 내부 전체 텍스트에 선택 언어를 적용한다.
- 변경할 때 현재 페이지, 스크롤 위치, 선택 날짜와 필터를 유지한다.
- 적용 성공 후 같은 기기·브라우저에 선택값을 저장한다. 다른 기기·브라우저이거나
  저장 데이터가 삭제된 경우에는 다시 한국어로 시작한다.
- 적용 성공 후 상단 버튼의 표시명을 선택한 언어명으로 바꾼다.
- 예상 가능한 공지는 언어별로 미리 작성한다. 새 공지는 관리자가 한국어로 저장하면
  한국어를 먼저 게시하고 현재 제공 중인 언어로 번역하며 영어 번역은 반드시 준비한다.
- 외국어 번역 실패는 한국어 게시를 막지 않고 실패한 언어의 공지만 번역 완료 전까지
  표시하지 않는다.
- 공지는 선택 언어의 번역이 완료된 항목만 보여 준다. 번역되지 않은 공지를 다른
  언어로 대체하거나 `번역 준비 중`으로 보여 주지 않는다.
- 적용에 실패하면 이전 언어·저장값·페이지 상태를 유지하고 이전 언어로
  `언어를 변경하지 못했어요. 다시 시도해 주세요`를 화면 하단에 3초 표시한다. 별도
  확인 버튼은 제공하지 않는다.

FAQ는 외부 페이지이며 앱의 번역·콘텐츠 관리 대상이 아니다.

## HOME-003 · 메인 최신 공지

메인 공지 영역에는 표시 대상 중 최초 등록 시각이 가장 최신인 제목 1개와 `전체보기`를
표시한다. 제목은 한 줄이며 넘치면 말줄임표로 처리한다. 제목과 `전체보기`는 모두
[NOTICE-001 알림 메시지 목록](notice.md)의 맨 위로 이동하고 특정 공지를 따로 열지 않는다.

- 일반 공지는 한국 시간 기준 당일 등록분만 후보로 삼는다.
- 분실물 공지는 등록 날짜와 관계없이 유지한다.
- 선택 언어 번역이 완료된 공지만 후보에 포함한다.
- 기존 공지를 수정해도 최초 등록 시각은 유지하며 수정만으로 최신 공지가 되거나 지난
  일반 공지가 다시 노출되지 않는다.
- 새 공지가 제공되면 새로고침 없이 최신 제목으로 자동 변경한다.
- 한국 시간 00:00에 전날 일반 공지를 제외하고 다시 선정한다.
- 후보가 없으면 `등록된 공지가 없어요`를 표시하되 `전체보기`는 유지한다. 선택하면
  빈 알림 메시지 목록으로 이동한다.
- 최초 조회 실패는 `공지를 불러오지 못했어요`로 표시한다. 정상 조회 뒤 갱신 실패는
  기존 제목을 유지하며 별도 오류 화면이나 재시도 버튼은 제공하지 않는다.

## HOME-005 · FAQ 바로가기

메인 FAQ 메뉴는 확정된 FAQ 외부 페이지를 새 탭으로 열고 기존 축제 앱 탭을 유지한다.
앱 내부 FAQ 화면, 질문 분류·표시, 앱 내 번역과 콘텐츠 관리는 제공하지 않는다.

- `Config.links.faq`에 승인된 HTTPS URL이 있으면 메뉴에 해당 링크를 연결한다. 공지사항·FAQ·
  공식 채널 링크는 catalog manifest의 `festivalLinks`로 게시 revision에 넣는다.
- URL이 `null`이면 임의 목적지로 이동하지 않는다. 실제 공개·비활성 표시 방식은 화면
  디자인을 따르되 링크가 없는 상태를 FAQ 내용으로 대체하지 않는다.
- 전달된 [6개 분류·25개 질문과 답변 초안](faq-draft.md)은 외부 페이지 작성 참고용
  기록이며 앱 공개 콘텐츠나 완료 조건이 아니다.
- 외부 페이지는 로그인 없이 접근할 수 있고 모바일에서 정상적으로 읽을 수 있어야 한다.

## HOME-006 · 스탬프투어 진입

메인의 `스탬프투어` 메뉴는 당일 참여 기록에 따라 [STAMP-001](stamp.md)로 연결한다.

- 당일 START 전에는 시작 화면으로 이동한다.
- START를 선택한 뒤에는 기존 스탬프 수집 화면으로 바로 이동한다.
- 현장 수령 인증이 성공한 뒤에는 수령 완료 상태가 유지된 수집 화면으로 이동한다.
- 한국 시간 날짜가 바뀌면 참여 시작 기록이 초기화되어 시작 화면으로 이동한다.
- 같은 기기·브라우저에서는 당일 시작·적립·수령 상태를 유지한다.

## HOME-007 · 외부인 티켓 진입

메뉴명은 `입장 티켓`이 아니라 `외부인 티켓`이다. 선택하면 재학생·외부인 유형 선택
화면 없이 [TICKET-001 외부인 티켓 송금 안내](ticket.md)로 바로 이동한다. 운영 기간
밖에도 메뉴는 유지하고 연결 화면에서 운영 전·마감·종료 상태를 안내한다.

## WELCOME-001 · 에리카 웰컴 데이 (제거됨)

2026-09-22 결정으로 이 기능을 없앤다. 고등학생 참여가 저조해 총학생회가 중단을
결정했다. 홈 메뉴의 `에리카 웰컴 데이` 항목과 이 절의 이전 명세, `festivalLinks`의
웰컴 데이 링크는 뺀다. 이전 명세는 [결정 대기 목록](decisions.md)의 2026-09-22
확정 기록에서 근거를 확인한다.

## HOME-003 · 공지 삭제 연동

[ADM-NOTICE-003](admin/notice.md) 삭제 성공 시 HOME-003에서도 새로고침 없이
해당 공지를 자동 제거하고 남은 노출 대상에서 최신 제목을 선정한다. 삭제 실패 시 기존
노출을 유지한다. 사용자 공지 목록의 신규 공지 버튼 정책과 삭제 반영은 구분한다.
