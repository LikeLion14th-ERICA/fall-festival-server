# 공연·라인업

[위키 홈](../README.md) · 읽는 때: 공연 진입·라인업·출연진 상세 변경

## SHOW-001 · 공연

하단 내비게이션의 `공연`에서 로그인 없이 축제 출연진과 날짜별 일정을 확인한다.
출연진 정보와 전체 공연 일정을 출시 전에 등록해야 한다.

공연 화면 상단에는 `라인업 / 타임테이블` 탭을 두고 최초 진입에는 라인업을 표시한다.
[타임테이블 상세 요구사항](timetable.md)은 같은 `SHOW-001` 기능의 일부다.

### 기본 상태와 탭 전환

| 시점 | 기본 날짜 |
|---|---|
| 축제 시작 전 | DAY 1 |
| 축제 기간 중 | 오늘에 해당하는 DAY |
| 축제 종료 후 | 축제 마지막 DAY |

- 라인업의 기본 분류는 `아티스트`다.
- 내부 탭을 전환하면 떠난 탭의 상태를 초기화하고 새 탭의 기본 상태를 표시한다.
- 라인업 탭에 다시 들어오면 기본 날짜·`아티스트`와 가로 스크롤 시작 위치를 표시한다.
- 다른 하단 메뉴에서 공연으로 다시 들어오면 라인업 탭의 기본 상태를 표시한다.
- 출연진 상세에서 뒤로 가는 경우에만 상세 진입 전 날짜·분류·가로 스크롤 위치를
  유지한다.

### 라인업 목록

- 날짜는 `DAY 1 / DAY 2 / DAY 3`, 분류는 `아티스트 / 콘테스트` 중 하나를 선택한다.
- `아티스트`는 선택한 날짜에 공연하는 아티스트, `콘테스트`는 해당 날짜에 공연하는
  콘테스트 참여팀만 표시한다.
- 출연진은 선택 날짜·분류 안의 공연 순서로 정렬한다.
- 대표 사진, 이름과 상세 진입용 `+` 버튼을 표시한다.
- 공연 순서에 따라 위쪽에 1·3·5번째, 그 사이 아래쪽에 2·4번째를 놓는 지그재그
  구성으로 오른쪽 가로 스크롤을 제공하고 스크롤바는 표시하지 않는다.
- 상세 화면은 `+` 버튼을 선택할 때만 연다. 사진과 이름 자체에는 동작을 두지 않는다.
- 해당 날짜·분류에 출연진이 없으면 `이 날은 출연진이 없어요.`를 표시한다.

### 출연진 상세

별도 화면에 다음을 표시한다.

- 출연진별 대표 사진 1장, 이름, 공연 날짜·시간과 간단한 소개
- 등록된 SNS 링크
- `대표곡` 영역에 최대 3곡의 곡명

대표 사진은 원본 비율을 유지해 표시 영역을 채우고 넘치는 부분을 중앙 기준으로
자른다. 표시 크기는 디자인팀이 정한다. 곡명을 선택하면 해당 YouTube 링크를 새
탭으로 연다. 콘테스트 참여팀도 같은 상세 구성을 사용한다. SNS나 대표곡처럼 등록되지
않은 정보는 제목과 영역을 모두 숨긴다.

### 오류

목록이나 상세 조회에 실패하면 `정보를 불러오지 못했어요.`와 `다시 시도` 버튼을
표시한다. 버튼을 선택하면 실패한 정보를 다시 조회하고 성공하면 정상 정보를 표시한다.

실제 출연진, 소개, SNS, 대표곡, 공연 순서와 사진 자산은 운영 콘텐츠로 준비한다.
