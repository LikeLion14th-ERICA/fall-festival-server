# 공연·타임테이블

[위키 홈](../README.md) · 읽는 때: 타임테이블·현재 시각선·반입 금지 물품 안내 변경

이 문서는 [`SHOW-001` 공연](lineup.md)의 타임테이블 탭을 정의한다.

## 타임테이블 요구사항

### 기본 화면과 일정

- DAY 1~3 일정을 나란히 배치하고 세로 시간축을 표시한다.
- 시간축은 17:00~22:00을 기본으로 하되 최종 공연 일정에 따라 조정한다.
- 공연 블록은 해당 날짜와 시작·종료 시간에 맞춰 배치하고 공연명을 표시한다.
- 타임테이블 탭에 다시 들어오면 기본 스크롤 위치를 표시한다.
- 전체 공연 일정은 출시 전에 등록한다.
- 공연 일정 변경은 개발자가 직접 수정한다. 관리자 페이지에서 공연 시간을 수정하는
  기능과 일정의 실시간 자동 갱신은 제공하지 않는다.
- 일정이 등록되지 않았으면 `공연 일정 준비 중이에요.`를 표시한다.

### 현재 시각선

축제 당일 17:00~22:00에만 오늘 날짜 열에 현재 시각을 나타내는 가로선을 표시한다.
사용자가 화면을 보는 동안 현재 시각에 맞춰 자동 이동한다. 축제 기간 밖이거나 당일
표시 시간 범위 밖이면 숨긴다.

최종 일정에 따라 시간축 범위를 바꿀 때 현재 시각선 표시 범위도 함께 바꾸는지는 아직
확정하지 않았다.

### 공연 정보 하단 팝업

공연 블록을 선택하면 타임테이블 위 하단 팝업에 공연명, 출연진, 시작·종료 시간과
등록된 간단한 안내를 표시한다. 안내가 없으면 해당 영역을 숨긴다. 팝업 바깥을
선택하면 닫고 별도 닫기 버튼은 표시하지 않는다.

### 반입 금지 물품 안내

- 타임테이블 상단에 총학생회에서 확정한 반입 금지 물품 목록과 관련 안내를 고정
  표시한다.
- 공연 진행 시간이나 별도 공지 등록 여부와 관계없이 타임테이블 탭에서 항상 표시한다.
- 총학생회에서 전달받은 최종 문구와 물품 목록은 개발자가 직접 등록·수정한다.
- 관리자 페이지의 공연 안내 등록·수정·게시 해제 기능은 제공하지 않는다.
- 사용자가 선택한 언어에 맞춰 사전에 준비한 안내문을 표시한다.

운영 중 우천이나 공연 변경 안내가 필요하면 별도 공연 관리자 기능이나 공지 유형을
추가하지 않고 기존 공지 시스템 범위에서 처리한다.

### 오류

일정이나 공연 정보 조회에 실패하면 `정보를 불러오지 못했어요.`와 `다시 시도` 버튼을
표시한다. 버튼을 선택하면 실패한 정보를 다시 조회하고 성공하면 정상 정보를 표시한다.
