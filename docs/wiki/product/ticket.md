# 외부인 티켓

[위키 홈](../README.md) · 읽는 때: 외부인 티켓·송금·현장 수령·티켓존 연결 변경

## TICKET-001 · 외부인 티켓 송금 안내

[HOME-007](home.md)의 `외부인 티켓`을 선택하면 별도 유형 선택 없이 바로 진입한다.
로그인 없이 당일 외부인 입장권 금액과 총액을 확인하고 외부 송금 수단을 이용한 뒤
현장에서 팔찌를 받도록 안내한다.

앱은 송금 정보와 외부 송금 화면 연결만 제공한다. 앱 내부 결제, 입금 확인, 티켓 발급,
구매 완료와 팔찌 수령 완료 기록은 제공하지 않는다. 총학생회 현장 담당자가 송금 앱의
완료 화면을 직접 확인하고 팔찌를 지급한다.

### 티켓 정보와 인원

- 티켓 종류는 외부인 1인 당일 입장권이다.
- 한국 시간 기준 당일 날짜를 자동 표시한다. 날짜 선택과 미래 날짜 구매는 제공하지 않는다.
- 인원은 1명으로 시작해 `− / 인원수 / +`로 한 명씩 바꾼다. 최소 1명이고 1명일 때
  `−`를 비활성화하며 별도 최대 인원 제한은 두지 않는다.
- 총액은 `1인 금액 × 선택 인원수`로 계산해 인원 변경 즉시 갱신한다.
- 앱 내부 구매 완료 상태는 두지 않는다.

명세에 적힌 1인 환경부담금 15,000원은 총학생회 확인 전 임시 기준이다. 확정 운영값으로
사용하지 않는다.

### 운영 시간과 상태

다음 시간도 지난 축제를 참고한 임시 기준이며 실제 축제 일정과 총학생회 확인이 필요하다.

| 항목 | 임시 기준 |
|---|---|
| 앱 송금 기능 제공 | 축제 당일 한국 시간 00:00~21:00 |
| 현장 티켓 수령·입장 | 13:00~21:00 |
| 입장 시작·마감 | 현장 상황에 따라 조정 가능 |

| 상태 | 표시와 동작 |
|---|---|
| 축제 시작 전 | `티켓 운영 전입니다` |
| 축제 당일 송금 시간 | 당일 정보와 송금·복사 기능 제공 |
| 현장 수령 시작 전 송금 | 당일 사전 송금은 가능하되 현장 수령 시작 시각 안내 |
| 당일 마감 뒤 | `오늘 티켓 수령이 마감됐어요` |
| 다음 축제일 00:00 | 당일 날짜 변경, 송금 기능 재활성화 |
| 마지막 축제일 종료 뒤 | `티켓 운영이 종료됐습니다` |

운영 전·마감·종료 상태에서는 토스 송금과 계좌번호 복사를 비활성화하고 계좌번호를
숨긴다. 메인의 외부인 티켓 메뉴는 운영 기간 밖에도 유지한다.

### 송금과 현장 수령

1. 당일 티켓 정보와 인원·총액을 확인한다.
2. `당일 구매한 티켓은 당일에만 사용할 수 있으며, 다른 날짜로 이월되지 않습니다.
   구매 후 사용하지 않은 티켓은 환불이 어려울 수 있으니, 방문 일정을 확인한 뒤
   송금해 주세요.`를 안내한다.
3. 토스 또는 사용하는 은행 앱에서 해당 금액을 송금한다.
4. 현장 외부인 티켓존에서 송금 완료 화면을 총학생회 담당자에게 보여 준다.
5. 담당자가 송금 내역을 확인한 뒤 입장 팔찌를 지급한다.

당일 현장 방문 전 송금은 허용한다. 현금 납부 가능 여부와 여러 명의 팔찌를 한 번에
받을 수 있는지는 아직 총학생회 확인 전이다.

### 토스와 계좌 복사

- `토스로 송금하기`는 토스 송금 화면으로 연결한다. 실제 송금은 토스에서 사용자가
  확인한 뒤 실행한다.
- 수취 계좌와 선택 인원 총액의 자동 입력 가능 여부·지원 범위는 개발팀 확인 전이므로
  확정하지 않는다.
- 토스에서 앱으로 돌아오면 인원을 1명, 금액을 1인 당일권 금액으로 초기화하고 결제
  완료 표시는 하지 않는다.
- 계좌 영역에는 은행명, 계좌번호, 예금주를 표시하되 실제 정보는 총학생회 전달 후
  반영한다. 실제 값은 축제 콘텐츠 revision이 아니라 운영 계좌 설정으로 등록하므로
  콘텐츠 게시나 rollback이 계좌를 바꾸지 않는다. 등록 전에는 운영 시간 안이어도
  계좌를 표시하지 않고 운영 준비 전 상태로 안내한다.
  절차는 [계좌 운영 설정](../engineering/operational-account-settings.md)을 따른다.
- `계좌번호 복사`는 계좌번호만 복사한다. 성공하면 `계좌번호가 복사됐어요`를 화면
  하단에 3초 표시하고 은행명·예금주와 나머지 화면 정보는 유지한다.

### 지도 연결

`티켓존 위치 확인하기`를 선택하면 앱 내부 [MAP-001 지도](map.md)로 이동해 외부인
티켓존을 중심으로 표시하고 위치를 강조한다. 티켓 수령 부스와 외부인 티켓존은 같은
장소이며 하나의 canonical `PLACE` 핀을 사용한다. 실제 좌표는 총학생회 승인 배치 자료를
받은 revision에 반영한다.

### 기존 와이어프레임 대응

사용자가 제공한 기능 명세의 프레임 번호 기준이다. Figma 자체 수정 완료를 뜻하지 않는다.

| 기존 프레임 | 처리 |
|---|---|
| 20번 재학생·외부인 선택 | 제외 |
| 21번 재학생 티켓 안내 | 이번 진입 흐름에서 제외 |
| 22번 외부인 구매 안내 | 필요한 정보를 송금 안내 화면으로 통합 |
| 23번 외부인 티켓 결제 | 외부인 티켓 송금 안내로 변경, 당일 날짜·인원·총액·운영 상태 반영 |

### 확인 필요

- 실제 축제 날짜, 환경부담금, 송금 기능 시간과 현장 수령·입장 시간
- 실제 은행명, 계좌번호와 예금주
- 외부인 티켓존 위치
- 현금 납부와 여러 명 팔찌 일괄 수령 가능 여부
- 토스 연결 방식과 계좌·총액 자동 입력 가능 범위
- 운영 전·마감·종료 상태의 최종 화면 디자인
