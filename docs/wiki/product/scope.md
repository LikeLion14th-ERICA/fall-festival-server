# 공개 범위와 기능 상태

[위키 홈](../README.md) · 읽는 때: 최초 숙지, 기능 추가·활성화·공개 여부 변경

- 하단 5탭: `홈 / 라인업 / 타임테이블 / 부스 & 마켓 / 지도`
- 홈: 현재 진행 중 이벤트, 공지, 챗봇, 언어 변경. FUN·스탬프가 채택되면 홈에서
  진입한다.
- 라인업: 축제 출연진 조회
- 타임테이블: 무대 일정, 현재 시각선, 현재 진행 공연 강조
- 부스 & 마켓: 부스·주점·플리마켓 목록과 상세, 메뉴·판매 품목, 지도 위치 연결
- 지도: 카테고리 필터, 구역 필터, 마커 정보. API v1은 일러스트 지도와 일반 지도
  좌표를 모두 표현하며, 실제 방식·지도 자산·사용 권한은 승인된 운영 설정으로 관리한다.
- 공지사항
- 지원 언어: 한국어, 영어, 중국어. 일본어는 후순위다.

`FAQ`, 공식 SNS 채널 구성, 라인업 검색·상세·SNS·추천곡·`내 일정에 추가`,
PWA 설치·오프라인 요건과 관리자 UI의 화면 범위는 Figma 또는 기획 제안에만 있으며
아직 공개 서비스 범위로 확정하지 않는다. API v1이 제공하는 관련 capability는 승인된
축제 회차에서 활성화되기 전까지 데이터나 UI를 공개하지 않는다. 관리자 API의
인증·권한 계약은 API v1을 따른다.

## 기능 상태

| 상태 | 기능 | 처리 원칙 |
|---|---|---|
| 확정 | 비로그인 공개 이용 | 공개 핵심 기능을 인증 뒤로 보내지 않음 |
| 확정 | 영어·중국어 지원 | 번역 대상 콘텐츠와 제공·승인 주체는 별도 확정 |
| 후순위 | 일본어 | 지원 언어처럼 노출하지 않음 |
| 확정 | 지도·라인업·타임테이블·부스 & 마켓·공지 | 공개 서비스 핵심 도메인 |
| 자료 대기 | 고등학생 환영 팝업/페이지 | 총학생회 자료와 노출 조건 없이 콘텐츠 작성 금지 |
| 협의 필요 | 스탬프 투어 | 식별·QR·중복 방지·개인정보·경품 정책 확정 전 개발 금지 |
| 보류 | 하루 단위 분실물 안내 | 공지 하위인지 별도 도메인인지 결정 필요 |
| 후보 | 폴라로이드, 텐텐식 술게임 | FUN 진입점이 있어도 구현 대상으로 간주하지 않음 |

실제 축제 날짜, 지도 원본, 마커 좌표, 라인업, 무대, 운영 시간, 메뉴, 공지,
공식 번역은 운영 자료 대기 항목이다.

## 승인 게이트

다음 기능은 승인 근거 없이 구현하거나 공개하지 않는다.

- 고등학생 환영 팝업/페이지: 총학생회 콘텐츠와 노출 조건 자료 대기
- 스탬프 투어: 참여 식별, QR, 중복 방지, 개인정보, 경품·수령 정책 협의 필요
- 분실물 안내: 하루 단위 운영 방식과 데이터 모델 보류
- FUN의 폴라로이드 및 텐텐식 술게임: 후보 기능
- 일본어: 후순위

보류 기능의 와이어프레임, 검증용 코드 또는 API 예시가 존재해도 공개 기능 승인으로
간주하지 않는다.
