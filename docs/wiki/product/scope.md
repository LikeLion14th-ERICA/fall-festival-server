# 공개 범위와 기능 상태

[위키 홈](../README.md) · 읽는 때: 최초 숙지, 기능 추가·활성화·공개 여부 변경

최신 기능 명세에 기능 ID와 동작이 정의된 항목을 현재 제품 범위로 본다. 명세 안에서
`임시 기준`, `확인 필요`, `미정`, `후속 작업`으로 표시한 값은 기능이 존재하더라도
확정 운영 데이터나 구현 결정으로 사용하지 않는다.

## 기능 상태

| 상태 | 기능 | 처리 원칙 |
|---|---|---|
| 명세됨 | `HOME-001` 재학생존 혼잡도 | 운영자 판단 상태와 시간 상태를 제공하고 변경을 새로고침 없이 반영 |
| 명세됨 | `HOME-002` 언어 변경 | 한국어 최초 표시, 준비가 끝난 언어만 한국어·영어·중국어 간체·일본어 우선순위로 노출 |
| 명세됨 | `HOME-003`, `NOTICE-001` | 당일 일반 공지와 유지 중인 분실물 공지를 언어별 규칙에 따라 제공 |
| 일부 미정 | `HOME-004` 외부 공지사항 | 지정 URL로 연결하되 URL의 날짜 검색 조건은 확인 필요 |
| 명세됨·URL 대기 | `HOME-005` FAQ | 로그인 없이 접근 가능한 외부 FAQ 페이지를 새 탭으로 연결한다. URL은 자료 대기이며 앱 FAQ 화면·콘텐츠 관리는 제외한다. |
| 명세됨·운영 자료 대기 | `HOME-006`, `STAMP-001` | 부스별 고유 QR·서버 익명 쿠키 적립·하루 4개·하루 1회 상품 규칙을 따르고, 현장 담당자가 수령 인증 코드를 입력·확인한다. 행사 기간·상품 운영 정보 확인 필요 |
| 명세됨·운영 자료 대기 | `HOME-007`, `TICKET-001` | 외부 송금 연결과 현장 수령을 제공하되 가격 25,000원은 확정, 정확한 시간·계좌·위치는 임시 또는 대기 |
| 명세됨 | `HOME-008` 공식 채널 | Instagram·YouTube·총학생회 홈페이지만 새 탭으로 연결 |
| 제거됨(2026-09-22) | `WELCOME-001` 에리카 웰컴 데이 | 고등학생 참여 저조로 총학생회가 기능 중단을 확정했다. 홈 메뉴·화면에서 뺀다. |
| 명세됨·출시 대기 | `LOVE-001` 한 줄 러브레터 | 하루 1회 익명 쪽지 교환. 개인정보·초기 쪽지·디자인·운영 검증 완료 전 비활성 |
| 명세됨·운영 자료 대기 | `GOODS-001` 굿즈샵 | 상품·옵션별 판매 상태·송금 안내를 제공하고 계좌 및 현장 예외 정책은 확인 필요 |
| 명세됨·콘텐츠 대기 | `SHOW-001` 공연 | 라인업·출연진 상세·타임테이블·고정 반입 금지 물품 안내를 하나의 공연 메뉴에서 제공 |
| 명세됨·콘텐츠 대기 | `BOOTH-001` 부스&마켓 | 세 분류의 목록·상세·별·공유·지도 연결을 제공 |
| 기본안·자료 대기 | `MAP-001` 지도 | 전체·구역별 일러스트 지도와 단일 핀 필터를 제공하고 최종 자산·배치는 후속 확정 |

## 공통 범위

- 모든 공개 기능은 로그인 없이 이용한다.
- 하단 메뉴는 `홈 / 굿즈샵 / 공연 / 부스&마켓 / 지도`다.
- 기능 명세에 계정, 회원가입, JWT가 없는 사용자 흐름에는 이를 추가하지 않는다.
- 같은 기기·브라우저 상태 유지가 명시된 언어, 별 저장, 당일 스탬프 외 저장 방식은
  기술 설계에서 결정하며 제품 문서에서 특정 저장소를 확정하지 않는다.
- 새로고침 없는 반영이 명시된 혼잡도, 메인 최신 공지와 굿즈 판매 상태에
  특정 실시간 통신 방식을 추가하지 않는다.

## 관리자 기능 상태

[관리자 Product](admin/README.md)는 다음 기능만 포함한다.

- `ADM-CROWD-001`
- `ADM-NOTICE-001`~`ADM-NOTICE-004`
- `ADM-GOODS-001`~`ADM-GOODS-002`
- `ADM-LOVE-001`~`ADM-LOVE-003` (출시 준비 전 비활성)

공연 일정·라인업·반입 금지 물품 안내, 재학생존 운영 시간, 부스·지도 편집과
스탬프 상품 처리는 관리자 기능 범위가 아니다. 공연 관리자 기능 ID는 정의하지 않는다.

## 공개 전 확인 게이트

- FAQ는 승인된 외부 HTTPS URL, 로그인 없는 접근과 모바일 가독성을 확인한다. 앱은
  해당 URL을 새 탭으로 연결하며 [질문·답변 초안](faq-draft.md)은 외부 콘텐츠 참고용이다.
- 에리카 웰컴 데이는 2026-09-22 결정으로 제거됐다. 홈 메뉴·화면·festivalLinks에서 빼는
  작업만 남는다.
- 스탬프투어는 실제 기간·수령 시간·상품 수량과 부스별 QR 배포·제시 방식(날짜별 토큰
  여부 포함)을 확정한다. 수령 인증 코드의 발급·안전한 전달·교체 담당자도 정하고, 실제
  값은 앱·문서·클라이언트에 넣지 않는다.
- 외부인 티켓은 실제 날짜·환경부담금·송금 가능 시간·계좌·티켓존과 토스 연결 가능
  범위를 확인한다. 가격 25,000원과 현장 수령 시작 13:00은 확정했다.
- 굿즈샵은 실제 상품 자산·계좌, 신규 옵션의 최초 판매 상태와 선송금 후 품절 대응을
  확인한다.
- 공연은 실제 출연진·일정과 총학생회가 확정한 반입 금지 물품 안내·번역문을 준비한다.
- 부스&마켓과 지도는 실제 참여 목록·지도 자산·핀 위치를 준비한다.
- 임시값이나 추정 구역을 실제 운영값으로 고정하지 않는다.
