# 실기기 검증 서비스

[위키 홈](../README.md) · 읽는 때: test 코드·PWA·푸시·익명 상태 복원 변경

사용자가 실제 기기에서 스탬프 유지와 푸시 수신을 검증했다고 확인했다.
기종·OS·브라우저 버전·유지 시간은 제공되지 않았으므로 지원 환경 전체의 검증으로
확대하지 않는다. 테스트용 증감 API는 QR·경품 운영 정책을 입증하지 않는다.

| 작업 | 원문 |
|---|---|
| 실행·환경 구성 | [test README](../../../test/README.md) |
| 세션·멱등 처리·상태 복원·푸시 설계 | [구현 기록](../../../test/docs/IMPLEMENTATION.md)의 해당 절 |
| 배포·보안·백업·복구 | [배포 runbook](../../../test/docs/FREE_SERVER_DEPLOYMENT.md)의 해당 절 |
| 프런트엔드 작업 | [프런트엔드 README](../../../test/frontend/README.md) |
| 검증 명령 | [검증 규칙](../workflow/validation.md) |
| 제품 적용 | [API 절 찾기](api-navigation.md), [스탬프](../product/stamp.md) |

검증된 기술 설계를 API에 적용하라는 최신 사용자 결정을 따른다. 단, 실제 운영 기능의
공개 승인과 기술 검증은 구분한다. API 원문을 계약으로 사용하고 테스트의 공용 접근 코드,
임의 증감·실험 일정·설치 요구를 공개 서비스 조건으로 복사하지 않는다.
